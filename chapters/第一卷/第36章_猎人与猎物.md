# 第三十六章 猎人与猎物

解码器的屏幕亮了一整夜。

蝰蛇坐在改装舰的货舱里，手指在键盘上敲。屏幕上的字符一行一行地滚动，像某种正在被剥开的洋葱——每剥一层，里面的东西就更刺眼。

陆川走进来的时候，她没抬头。

"协议七的加密层比其他协议厚四倍。"蝰蛇说，"用了朱庇特军用级编码。三重嵌套。外层是行为触发条件，中层是执行序列，内层——"

她停了一下。

"内层是什么。"

"目的。"蝰蛇的手指在键盘上敲了两下，屏幕上的字符停下来，"我刚解到中层。"

陆川在她旁边蹲下来。货舱的金属地板冰凉，透过裤子渗进膝盖。解码器的白光打在他脸上，让他眼角的细纹变得很清晰。

屏幕上的文字：

```
协议七·中层·执行序列

触发条件：石鸦号沉没不可逆。
执行内容：种子舱全量投放。
投放坐标：未命名星系（九段加密）。
投放方式：引力弹弓弹射。
备注：意识转移协议同步启动。备份完成确认后执行人记忆清除。
```

意识转移。记忆清除。

陆川的拇指在膝盖上停了一下。

"记忆清除。"

"对。"蝰蛇的声音很平，像在念一段操作手册，"执行协议七之后，执行人的相关记忆会被清除。不是全部——只是协议相关的部分。"

"所以你不记得。"

"所以我不记得。"蝰蛇终于抬头看了他一眼。解码器的光在她脸上把颧骨的阴影拉得很长。"但现在我正在把那些记忆解回来。"

---

韩霜的声音从通讯频道里传来。

"茶隼护盾回到百分之二十二了。韩霜修了一夜，补了三块装甲板，换了两个护盾发射器。但结构应力还超标百分之七。"

"够用吗。"

"跑可以。打不行。"

赵一鸣的声音插进来："铁砧状态正常。装甲差百分之四十，底漆没漆完，但引擎出力达标。锁定系统——"

他停了一下。

"锁定系统怎么了。"

"零点三秒。"赵一鸣说，"比原系统快零点一秒。数据核心的算力挂上来了。"

陆川没说话。他盯着解码器的屏幕。蝰蛇的手指又开始敲键盘，字符继续滚动。

"老钱。"

"在。"

"影子网络恢复到多少了。"

"百分之四十五。"老钱的声音沉缓，"够用。波赫文方向的通讯能接，更远的还不行。"

"苏铭。"

"后勤网覆盖三个星系。第一跳到第三跳都有补给点。第四跳之后——没有数据。"

"没有数据。"

"对。死寂空间没有补给站，没有信标，没有星图。第四跳之后我们就是瞎子。"

陆川站起来。膝盖上的凉意还没散。他走到货舱门口，手按在门框上。金属边缘硌着掌心。

"继续解。"他对蝰蛇说。

---

又过了两个小时。

蝰蛇的手指终于停了下来。

屏幕上的最后一行加密字符被替换成明文。蝰蛇盯着屏幕看了几秒，然后慢慢把双手从键盘上收回来，放在膝盖上。

"解完了。"她说。

陆川走过去。

屏幕上的文字：

```
协议七·内层·目的

黑羊组织终极目标：种子舱。

种子舱内容：地球人意识备份（第一批）。
备份来源：EVE之门穿越事件。
备份技术：朱庇特意识转移协议（原型）。
投放目的：在未命名星系建立地球人意识恢复基地。
恢复条件：需要解码器+行权代码（活体生物特征）。

备注：
种子舱不是武器。是保险箱。
黑羊追杀零号猎兵的目的——夺取解码器。
解码器是唯一能激活种子舱的密钥。
石鸦号沉没——保护种子舱坐标不被黑羊获取。
协议七——最后手段。沉船之前把坐标藏进解码器的加密层。
```

货舱里安静了很久。

蝰蛇的拇指在膝盖上慢慢摩挲，指腹蹭过裤子的接缝。

"种子舱。"她说。"里面装的是人。"

陆川没说话。他的视线落在屏幕上最后一行字——石鸦号沉没，保护种子舱坐标。二十一年。方远征守了三十一年。老钱躲了十五年。蝰蛇什么都不记得。

都是为了这个。

"黑羊要的是解码器。"陆川的声音很低，"他们一直要的就是解码器。"

"对。"蝰蛇说，"解码器能激活种子舱。种子舱里是地球人的意识备份。如果黑羊拿到——"

她没说完。

但陆川听懂了。意识备份。如果黑羊拿到，他们可以控制谁醒来，谁不醒来。可以复制。可以修改。可以把人变成数据，再把数据变成他们想要的人。

"所以方远征被灭口。"陆川说。

"他守了三十一年。"蝰蛇的声音变得更低，"他知道种子舱的坐标。黑羊不需要他活着——他们只需要解码器。"

"老钱呢。"

"老钱不知道种子舱的事。"蝰蛇说，"他只知道名单。名单上的人——都和石鸦号有关。"

陆川的拳头在身侧慢慢攥紧，又松开。

---

他打开通讯频道。

"全员通讯。"

几秒钟后，六个声音依次确认。

"老钱。"

"在。"

"赵一鸣。"

"在。"

"韩霜。"

"在。"

"苏铭。"

"在。"

"蝰蛇。"

"在。"

陆川靠在货舱门框上。金属硌着肩胛骨。他低头看了一眼手腕上的旧表——指针走到裂痕的位置，顿了一下，跳过去。

"协议七解完了。"他说，"我告诉你们结果。"

他用最简短的语言把协议七的内容复述了一遍。种子舱。意识备份。黑羊的真正目的。石鸦号沉没的原因。

说完之后，频道里安静了几秒。

赵一鸣的声音第一个响起来："所以黑羊追了我们一路——不是为了灭口。是为了解码器。"

"对。"

"解码器能激活种子舱。种子舱里是地球人的意识备份。"赵一鸣的声音停了一下，"第一批。"

"对。"

苏铭的声音从频道里传来，带着某种陆川很少听到的紧绷："穿越不是随机的。种子舱。第一批投放。意识备份——"

"苏铭。"陆川打断他。

"我在听。"

"先不说这个。"

苏铭没再开口。

韩霜的声音冷冷的："茶隼结构应力还超标百分之七。如果黑羊追上来——"

"他们已经在追了。"老钱的声音从频道里传来，"猎杀组七十二小时通牒。现在已经过了多久？"

陆川算了一下。"五十八小时。"

"还有十四小时。"老钱说。

十四小时。

陆川的手指在门框上慢慢收紧。金属边缘硌进掌心，有点疼。

"陆川。"蝰蛇的声音从身后传来。她还在货舱里，坐在解码器前面。屏幕的白光照着她的后背。

"嗯。"

"协议七里还有一条。"她说，"我没念。"

"什么。"

蝰蛇的手指在键盘上敲了一下。屏幕上跳出一行新的文字：

```
附加条款：若解码器落入非授权方，种子舱自毁协议启动。
自毁方式：引力坍缩。
影响范围：未命名星系全境。
```

全境。

陆川的呼吸停了半拍。

"如果黑羊拿到解码器——"

"种子舱自毁。"蝰蛇说，"整个未命名星系。全部。"

"包括里面的人。"

"包括里面的一切。"

货舱里又安静了。解码器的风扇嗡嗡响，声音很轻，但在沉默里显得格外清晰。

---

陆川站在改装舰的舱门前，看着舷窗外。

星门还在那里。暗红色的环体悬浮在虚空中，边缘的信号灯以四十七秒的间隔闪烁。亮。暗。亮。暗。像心跳。

石鸦号的沉没坐标在星门里面。

种子舱在石鸦号里面。

黑羊在后面追。

十四小时。

陆川的手指在身侧慢慢攥紧，又松开。他转过身，面对通讯面板。

"老钱。"

"在。"

"猎杀组的移动基地在哪。"

老钱沉默了两秒。"引力盲区。改装巡洋舰。依托石鸦号残骸的引力场做掩护。"

"他们比我们先到。"

"对。他们在等。"

"等什么。"

"等我们进星门。"老钱的声音变得更低，"星门只能单向激活。进去之后——他们在外面堵。"

陆川的拇指在门框边缘摩挲了一下。指腹蹭过金属的毛刺，有一点粗糙的触感。

"如果我们不进星门呢。"

"种子舱永远打不开。"蝰蛇的声音从货舱里传来，"解码器的坐标指向星门内部。不进去——什么都拿不到。"

"如果我们进去呢。"

"黑羊在外面堵。"赵一鸣的声音从频道里传来，"出来的时候——"

他没说完。

陆川盯着舷窗外的星门。暗红色的光在虚空中一明一暗。四十七秒。

"不等了。"他说。

频道里没人说话。

"我们一直在跑。"陆川的声音很平，"从塔诺伦跑到波赫文，从波赫文跑到这里。黑羊追了我们六个月。六个月。"

他的手指在门框上慢慢收紧。

"猎人追猎物。"他说，"猎物跑。但猎物跑得再快——还是在跑。"

"你要干什么。"韩霜的声音从频道里传来。

"不跑了。"陆川说，"反向。"

---

苏铭的声音从频道里传来，带着某种他很少有的急促："反向——你的意思是主动出击？"

"对。"

"目标？"

"猎杀组的移动基地。"陆川说，"老钱，引力盲区的坐标。"

老钱沉默了三秒。然后他的声音从频道里传来，沉缓，一字一字："第七跳之后。石鸦号残骸的引力场边缘。改装巡洋舰停泊在残骸的阴影里。"

"几艘。"

"一艘。改装狞獾级。火力大概是茶隼的六倍。"

六倍。

赵一鸣的声音从频道里传来："六倍。我们六艘船加起来——"

"不够。"陆川说，"正面打不够。"

"那怎么打。"

陆川没立刻回答。他转头看向货舱里的蝰蛇。

蝰蛇坐在解码器前面，手指搭在键盘上。屏幕的光照着她的脸。她没看他。

"蝰蛇。"

"嗯。"

"石鸦号的敌我识别码——解码器里有。"

蝰蛇的手指在键盘上停了一下。

"五艘。"她说，"石鸦级。零号猎兵编制舰。"

"能用吗。"

蝰蛇转头看着他。解码器的白光打在她瞳孔里，像两个小小的亮点。

"敌我识别码可以骗过自动锁定系统。"她说，"黑羊的狞獾级用的是加达里军用火控——识别到友方信号不会开火。"

"能骗多久。"

"足够接近。"蝰蛇说，"接近到鱼雷射程之内。"

鱼雷射程。十五公里。

陆川点点头。他转回通讯面板。

"计划。"他说，"蝰蛇用解码器激活石鸦级敌我识别码。我们的船伪装成零号猎兵编队。接近猎杀组移动基地。进入鱼雷射程——"

"然后呢。"韩霜的声音冷冷的。

"然后打。"陆川说，"韩霜，茶隼的护盾能撑几轮。"

"结构应力超标百分之七。"韩霜停了一下，"如果只挨一轮——能撑。两轮——不确定。"

"一轮够了。"陆川说，"蝰蛇贴脸放鱼雷。赵一鸣电子干扰锁火控。韩霜保护盾。苏铭算弹道。老钱——"

"我在外围。"老钱的声音从频道里传来，"影子网络覆盖引力盲区。通讯干扰。让他们叫不了援军。"

陆川的手指在门框上慢慢松开。掌心有一个浅浅的压痕，金属边缘留下的。

"六个人。"他说，"一个都不能少。"

频道里安静了一秒。

然后赵一鸣的声音响起来："铁砧首秀。装甲差百分之四十。底漆没漆完。"他停了一下，"但锁定系统快了零点一秒。"

韩霜的声音："茶隼能撑一轮。"

苏铭的声音："弹道计算需要四十七秒。"

老钱的声音："影子网络就位。"

蝰蛇的声音从货舱里传来，短，硬："跟上。航线清空。"

陆川深吸了一口气。舷窗外的星门还在闪烁。四十七秒。亮。暗。亮。暗。

他转身走向舱门。

"各舰就位。"他说，"一小时后出发。"

---

舱门关上的时候，陆川在走廊里停了一下。

金属走廊。蓝色导引灯。靴子踩在地板上，声音很轻。和波赫文的走廊一样窄。和塔诺伦的走廊一样窄。和伊毕斯的走廊一样窄。

他低头看了一眼口袋。伊毕斯的旧操纵杆还在里面。杆径差两毫米，装不上茶隼。但他一直带着。

口袋里还有一张卡。一片芯片。三组坐标。

从塔诺伦到波赫文。从波赫文到死寂空间。从猎物到猎人。

他把手插进口袋，指尖碰到操纵杆冰凉的金属表面。

然后他走向驾驶舱。
