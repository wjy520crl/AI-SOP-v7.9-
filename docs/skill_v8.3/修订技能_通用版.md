# 修订技能（通用版）v1.0

> **质检不通过后的修改指导**。根据质检报告定位问题，提供具体修改策略和示例。
> 
> 使用流程：质检报告 → 问题诊断 → 修改策略 → 改写执行 → 迭代检查

---

## 一、问题诊断

根据质检报告，将问题分类为以下类型：

| 问题类型 | 典型表现 | 严重程度 |
|---------|---------|---------|
| **结构问题** | 段落过长、节奏失衡、信息密度不均 | 🔴 高 |
| **AI味问题** | 陈词滥调、收束结尾、情绪直白 | 🔴 高 |
| **衔接问题** | 章间断裂、时间跳跃突兀 | 🟡 中 |
| **细节问题** | 形容词堆砌、体感重复 | 🟡 中 |
| **逻辑问题** | 空降结论、因果不清 | 🟡 中 |

**诊断原则**：先解决🔴高优先级问题，再处理🟡中优先级问题。

## 二、修改策略

### 2.1 结构问题修改

#### 问题：段落过长（>5行）

**诊断**：
- 检查：段落是否超过5行（手机屏）
- 原因：信息堆砌、缺乏节奏感

**修改策略**：
1. **找到断点**：在动作转换、视角切换、时间跳跃处断开
2. **制造波动**：长段后接1-2行短段
3. **删除冗余**：每段只保留一个核心信息

**Before/After示例**：

```
【Before】
陈默走进房间，环顾四周，发现墙上有一幅画，画的是一片麦田，
他想起小时候在乡下度过的夏天，那时阳光很好，蝉鸣声不断，
他和爷爷一起在田里劳作，虽然辛苦但很开心，那是他最怀念的时光。
（4行，信息混杂：动作+环境+回忆+情感）

【After】
陈默走进房间。

墙上挂着一幅画。麦田，金黄的，一直延伸到地平线。

他停下脚步。

那是他小时候的记忆——乡下的夏天，阳光把蝉鸣晒得发烫，
他和爷爷在田里弯腰劳作，汗水滴进泥土里。
（5段，每段一个焦点：动作→环境→反应→回忆）
```

---

#### 问题：节奏失衡（全篇匀速）

**诊断**：
- 检查：句子长度是否均匀分布
- 标准：短句40-50%，中句30-40%，长句10-20%

**修改策略**：
1. **标记句子长度**：统计每句字数
2. **打破均匀**：在长句群后插入短句（3-8字）
3. **制造突变**：紧张场景用短句，过渡场景用中长句

**Before/After示例**：

```
【Before】
他推开门，看到房间里站着一个人，那个人背对着他，
身材高大，穿着一件黑色的风衣，他感到有些紧张，
但还是走了进去，那个人慢慢转过身来，露出一张陌生的脸。
（全是中句，匀速，无节奏）

【After】
他推开门。

房间里站着一个人。

背对着他。高大。黑风衣。

他走进去。

那个人转过身。

一张陌生的脸。
（短句制造紧张感，突变打破匀速）
```

---

#### 问题：信息密度不均（连续300字无增量）

**诊断**：
- 检查：每300字是否有信息增量/冲突/反转
- 标记：连续无增量段落

**修改策略**：
1. **删除冗余描写**：环境、心理、回忆中重复的部分
2. **插入冲突点**：在平淡处加入小阻碍/发现/疑问
3. **压缩过渡**：用1句话完成场景转换

**Before/After示例**：

```
【Before - 信息密度过低】
陈默走出房间，沿着走廊向前走。走廊很长，两边的墙壁是白色的，
上面挂着一些画。他一边走一边看着这些画，画的内容各不相同，
有的是风景，有的是人物。他继续向前走，脚步声在走廊里回响。
（200字，无信息增量，纯环境描写）

【After - 信息密度提升】
陈默走出房间，沿着走廊向前走。

第三幅画让他停下脚步——画里是他昨天才见过的那个人。

他回头看了眼来时的方向。门关着。

脚步声从走廊尽头传来。
（压缩环境，插入发现+疑问+冲突）
```

### 2.2 AI味问题修改

#### 问题：AI收束式结尾

**诊断**：
- 检查：最后3段是否有以下模式
  - 「他知道...」「他不知道的是...」
  - 「从此刻起...」「新的XX开始了」
  - 「这一切才刚刚开始」
  - 情感总结句
  - 排比收束

**修改策略**：
1. **删除总结句**：直接砍掉收束式表达
2. **用动作收尾**：以角色的具体动作结束
3. **用物件锚定**：以某个物品的特写结束
4. **停在未完成**：动作做到一半，自然留白

**Before/After示例**：

```
【Before - AI收束】
陈默看着窗外的夜色，心中涌起一股复杂的情绪。
他知道，从这一刻起，他的生活将彻底改变。
新的征程，才刚刚开始。

【After - 动作收尾】
陈默看着窗外的夜色。

手指在玻璃上划出一道雾气，又慢慢散去。

他没有关灯。

【After - 物件锚定】
陈默看着窗外的夜色。

桌上的手机亮了。一条新消息。

他拿起来，屏幕的光映在他脸上。

【After - 未完成】
陈默看着窗外的夜色。

他伸出手，碰到门把手——

停住了。
```

---

#### 问题：陈词滥调

**诊断**：
- 检查：是否有以下表达
  - 「指节因用力而发白」
  - 「嘴角勾起一抹弧度」
  - 「眼神冷得像冰」
  - 「洗得发白的XX」
  - 「倒吸一口凉气」

**修改策略**：
1. **具体化**：写具体的物理细节，而非概括描述
2. **陌生化**：用不常见的动词/名词组合
3. **体感化**：写身体感受而非视觉概括

**Before/After示例**：

```
【Before - 陈词滥调】
他握紧拳头，指节因用力而发白，眼神冷得像冰。

【After - 具体化】
他的指节抵在桌面上，压出四个浅坑。桌面是木头的，
漆已经磨掉了，露出下面的纹理。

【After - 体感化】
他的手指收紧，指甲陷进掌心的肉里。疼。但他没松手。
```

---

#### 问题：情绪直白

**诊断**：
- 检查：是否有「他很伤心」「她感到害怕」等直通表达

**修改策略**：
1. **身体反应替代**：用生理反应传递情绪
2. **环境映射**：用环境变化暗示情绪
3. **动作变形**：情绪影响动作方式

**Before/After示例**：

```
【Before - 情绪直白】
听到这个消息，他感到很愤怒。

【After - 身体反应】
听到这个消息，他的后槽牙咬紧了。耳朵里嗡嗡响。

【After - 动作变形】
听到这个消息，他把杯子放下。放得太重，水溅出来，
在桌面上漫开一片。他没擦。

【After - 环境映射】
听到这个消息，窗外的蝉鸣突然变得很吵。阳光刺眼。
他拉上了窗帘。
```

### 2.3 衔接问题修改

#### 问题：章间断裂

**诊断**：
- 检查：本章前200字是否回应前章钩子
- 前章钩子类型：A动作/B信息/C情感

**修改策略**：

| 前章钩子类型 | 修改方法 |
|-------------|---------|
| A. 动作悬念 | 补时间衔接+状态衔接+动作完成 |
| B. 信息悬念 | 补信息处理+决策/反应 |
| C. 情感悬念 | 补情感延续+行动转化 |

**Before/After示例**：

```
【场景】
前章结尾：陈默推开门，看到房间里站着一个人——（A型动作悬念）

【Before - 章间断裂】
第2章：陈默在房间里搜索线索。墙上的画引起了他的注意...
（未回应"房间里的人"，直接跳走）

【After - 补衔接】
第2章：

门在身后关上。咔哒一声。

房间里的人转过身来。是个女人，三十岁左右，
穿着白大褂，手里拿着一个文件夹。

"你迟到了。"她说。

陈默没动。他的手还在门把手上。
（时间衔接：门关上；状态衔接：两人对峙；动作完成：看到人+对话）
```

---

#### 问题：时间跳跃突兀

**诊断**：
- 检查：时间跳跃是否有明确标记
- 大跨度跳跃（>1天）是否有过渡

**修改策略**：
1. **插入过渡句**：明确说明时间流逝
2. **用变化暗示**：环境/人物状态的变化暗示时间
3. **保留关键帧**：只保留跳跃后的第一个场景

**Before/After示例**：

```
【Before - 突兀跳跃】
陈默躺在床上，想着今天发生的事。

三天后，他站在公司门口。
（突兀，无过渡）

【After - 平滑过渡】
陈默躺在床上，想着今天发生的事。

接下来的三天，他没出门。外卖盒堆在墙角，
手机屏幕亮了又暗。第三天晚上，他洗了个澡，
刮了胡子，站在公司门口。
（过渡句+状态变化暗示时间流逝）
```

### 2.4 细节问题修改

#### 问题：形容词堆砌

**诊断**：
- 检查：单个主体是否超过2个形容词
- 检查：是否有「的...的...的...」链条

**修改策略**：
1. **删减**：只保留最关键的1个形容词
2. **转化**：形容词转化为动词或名词
3. **分散**：把修饰分散到不同句子

**Before/After示例**：

```
【Before - 堆砌】
那个高大威猛、满脸胡须、眼神凶狠的男人走了过来。
（3个形容词堆叠）

【After - 删减】
那个男人走了过来。很高，影子把路灯都遮住了。

【After - 转化】
那个男人走了过来。脚步声很重，胡须遮住了半张脸，
目光扫过来，像在看一件物品。
（形容词→动词/动作）
```

---

#### 问题：体感重复

**诊断**：
- 检查：同一身体感受是否超过3次/章
- 常见重复：伤口疼、疲惫、寒冷、紧张

**修改策略**：
1. **替换感官类型**：视觉→听觉→触觉→嗅觉
2. **换部位**：手→脚→背→头
3. **用变体**：详见《核心规则库》第五章5.3节

**Before/After示例**：

```
【Before - 重复】
他的伤口很疼。他忍着疼向前走。疼得他冒冷汗。
（"疼"出现3次，已超标）

【After - 变体+换感官】
他的伤口在发烫。（触觉）

他向前走，每一步都有撕裂感。（体感变体）

血渗出来，黏在衣服上。腥味。（嗅觉+视觉）
```

---

### 2.5 逻辑问题修改

#### 问题：空降结论

**诊断**：
- 检查：角色是否有无依据的猜测/判定
- 常见形式：「他意识到...」「他发现...」「原来...」

**修改策略**：
1. **前置线索**：在结论前插入观察细节
2. **改为疑问**：不确定的猜测用疑问形式
3. **他人告知**：通过对话让其他角色提供信息

**Before/After示例**：

```
【Before - 空降结论】
陈默看着那幅画，意识到这是爷爷留下的线索。
（无依据，直接得出结论）

【After - 前置线索】
陈默看着那幅画。麦田的角落里，有一个小小的身影，
背对着观众，手里拿着什么东西。

他凑近看。那个身影的轮廓，和爷爷的照片一样。

画框背面，有一行小字："找到它。"

他的手抖了一下。
（细节→观察→关联→结论）
```

## 三、改写示例库

### 3.1 开篇改写

**问题**：开篇200字无抓手

```
【Before】
陈默是一个普通的上班族，每天朝九晚五，生活平淡无奇。
直到那一天，一切都改变了。
（背景介绍，无抓手）

【After - 动作开篇】
陈默推开办公室的门，发现他的座位上有个人。

那个人穿着他的外套，用他的电脑，
听到开门声，转过头来——

和他长得一模一样。
（第1句：动作；第5句：冲突/钩子）

【After - 对话开篇】
"你只有三分钟。"

陈默看着手机上的倒计时，02:59，02:58...

他冲进电梯，按下17楼。

电梯门缓缓关上。

然后停电了。
（第1句：对话；第6句：冲突）
```

---

### 3.2 对话改写

**问题**：对话像座谈会，缺乏动作和潜台词

```
【Before】
"你为什么要这么做？"陈默问。
"因为我必须这么做。"对方回答。
"你知道后果吗？"
"我知道。"
（纯对话，无动作，无潜台词）

【After】
"你为什么要这么做？"陈默问。

对方没回答。他低头看着手里的杯子，
转了一圈，又转了一圈。

"因为我必须这么做。"

"你知道后果吗？"

杯子停了。对方抬起头，笑了一下。
那笑容让陈默的后背发凉。

"我知道。"
（插入动作+反应+潜台词）
```

---

### 3.3 战斗场景改写

**问题**：战斗像回合制，缺乏紧张感

```
【Before】
陈默冲向敌人，挥出一拳。敌人躲开了，
反击一拳。陈默挡住，然后踢出一脚。
敌人后退，陈默追上去...
（回合制，匀速，无感官）

【After】
陈默冲上去。

第一拳，空了。风声从耳边划过。

敌人的反击来得很快。他侧身，
肩膀撞在墙上，疼。

第二拳。他矮身，感觉对方的拳风从头顶扫过。

然后踢出去。踢中了。脚踝传来撞击的钝感。

敌人后退，撞翻了椅子。
陈默没停。他扑上去——
（短句+感官+连续动作）
```

## 五、常见问题FAQ

**Q1：修改后字数不够怎么办？**
A：扩展场景细节，增加身体感受和环境描写，而非添加无关情节。

**Q2：修改后感觉"味道"变了怎么办？**
A：检查是否过度删除，保留原文的1-2个核心意象作为锚点。

**Q3：一个问题改了5遍还是不行？**
A：考虑重写整个段落，而非局部修改。有时推倒重来更高效。

**Q4：多个问题同时出现，先改哪个？**
A：按优先级：结构问题 → AI味问题 → 衔接问题 → 细节问题。

**Q5：修改后评分反而下降了？**
A：检查是否引入新问题（如修改衔接时破坏了节奏）。回滚到上一版重新修改。
