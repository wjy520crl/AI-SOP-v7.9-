# 大纲生成技能（通用版）v1.0

> 专门用于生成小说大纲。包含大纲结构、节拍设计、伏笔规划、张力曲线设计。
> 生成大纲后，使用「每章创作prompt模板」进行单章创作。

---

## 使用方式

1. 先完成「初始化技能」中的项目设定
2. 使用本技能生成全书大纲
3. 大纲采用四级结构：卷级 → 章级 → 场景 → 节拍

---

## 一、大纲结构体系

### 四级结构定义

```
全书大纲（卷级）
├── 卷1大纲（章级）
│   ├── 第1章（场景级）
│   │   ├── 场景1（节拍级：3-5个要点）
│   │   └── 场景2（节拍级）
│   ├── 第2章
│   └── ...
├── 卷2大纲
└── ...
```

### 各级详细说明

| 级别 | 粒度 | 内容 | 字数 |
|------|------|------|------|
| **卷级** | 宏观 | 本卷目标、核心冲突、人物弧光节点、伏笔收放 | 500-800字 |
| **章级** | 中观 | 章节类型、场景列表、核心任务、钩子设计 | 200-300字 |
| **场景级** | 微观 | 场景地点、时间、参与人物、场景目标 | 50-100字 |
| **节拍级** | 执行 | 具体动作/对话/事件，按顺序排列 | 3-5个要点 |

## 二、大纲生成流程

### Step 1: 生成全书架构（卷级）

**输入**：初始化技能中的项目设定
**输出**：全书卷级大纲

**每卷必须包含**：
```markdown
## 第X卷：[卷名]

### 本卷目标
[本卷要完成的叙事目标]

### 核心冲突
[本卷的主要冲突]

### 人物弧光节点
- 主角：[从什么状态到什么状态]
- 关键配角：[变化描述]

### 伏笔处理
- 新埋伏笔：[伏笔名称] → [作用]
- 回收伏笔：[伏笔名称] → [揭示内容]

### 卷末钩子
[为下一卷留下的悬念]
```

### Step 2: 生成章级大纲

**输入**：卷级大纲
**输出**：每卷40-60章的章级大纲

**每章必须包含**：
```markdown
## 第X章：[章标题]
**类型**：[📍高潮/🌙低潮/💔情感/💬对话]
**场景**：[地点1] → [地点2]
**时间**：[相对时间，如：灾变第X天 14:00-16:00]

### 场景列表
1. [场景1名称]（地点）
2. [场景2名称]（地点）

### 节拍要点
1. [第一个节拍：动作/事件]
2. [第二个节拍：反应/决策]
3. [第三个节拍：转折/发现]
4. [第四个节拍：推进/升级]
5. [第五个节拍：钩子铺垫]

**伏笔**：[本章埋伏笔或回收伏笔]
**情感锚点**：[本章情感载体]
**章末状态**：[地点/人物状态/关键物品位置]
```

### Step 3: 生成场景级大纲

**输入**：章级大纲中的单章
**输出**：场景详细设计

**每个场景必须包含**：
```markdown
### 场景[X]：[场景名]
- **地点**：[具体位置]
- **时间**：[相对时间，精确到小时]
- **人物**：[出场角色列表]
- **场景目标**：[这个场景要完成什么叙事功能]
- **主导意象域**：[从初始化技能的四域中选择]
- **情绪基调**：[紧张/平静/悲伤/希望等]

#### 节拍设计
1. [进入场景：如何开始]
2. [核心互动：发生什么]
3. [转折/发现：有什么变化]
4. [退出场景：如何结束，留下什么状态]
```

## 三、章节类型设计指南

### 📍 高潮章节设计

**功能**：推进情节、战斗/发现/冲突
**结构**：
```
节拍1: 威胁出现/任务触发
节拍2: 准备/应对
节拍3: 核心对抗（第一轮）
节拍4: 转折/危机升级
节拍5: 高潮对决/关键发现
节拍6: 结果/代价
节拍7: 章末钩子（A/B/C型）
```

**钩子类型**：
- **A. 动作悬念**：未完成动作，停在关键时刻
- **B. 信息悬念**：新发现/线索，待解读
- **C. 情感悬念**：内心波动/决策点

### 🌙 低潮章节设计

**功能**：氛围沉淀、读者喘息、人物内心
**结构**：
```
节拍1: 日常维护/整理
节拍2: 环境描写/氛围营造
节拍3: 回忆闪回/内心独白
节拍4: 微小变化（打破平淡但不推进主线）
节拍5: 自然结束（D/E型弱钩子或无钩子）
```

**禁止**：新钩子、新悬念、重大发现、新能力

### 💔 情感章节设计

**功能**：深化人物内心、情绪爆发
**结构**：
```
节拍1: 情绪积累（铺垫）
节拍2: 触发事件（导火索）
节拍3: 情绪反应（内心波动）
节拍4: 非理性时刻（崩溃/错误决定）
节拍5: 后果显现（必须有后果）
节拍6: 章末情感钩子（C型）
```

**要求**：每3-4章必须有"非理性时刻"，必须有后果

### 💬 对话章节设计

**功能**：推进人际关系、信息交换
**结构**：
```
节拍1: 对话开场（建立场景）
节拍2: 第一轮交流（信息交换）
节拍3: 试探/博弈（潜台词）
节拍4: 关键信息 reveal
节拍5: 对话收束（关系变化）
节拍6: 章末钩子（B型或C型）
```

**要求**：每4-5章必须有一次实时对话

## 四、张力曲线设计

### 卷级张力曲线

```
张力
10 |                              ★（卷末高潮）
 9 |                         ★★★
 8 |                    ★★
 7 |               ★
 6 |          ★★★
 5 |     ★
 4 | ★★
 3 |
 2 |
 1 |_____________________________________________
    第1章                              第40章
```

**设计原则**：
- 卷首：中等张力（5-6分），快速建立情境
- 卷中：波浪式上升，小高潮（7-8分）穿插低潮（3-4分）
- 卷末：大高潮（9-10分），然后适度回落留钩子

### 章间节奏分布

推荐分布（40章/卷为例）：
| 章节类型 | 数量 | 分布位置 |
|---------|------|----------|
| 高潮章节（📍） | 12-15章 | 每2-3章一次，卷末必高潮 |
| 低潮章节（🌙） | 10-12章 | 每2-3章插入一次 |
| 情感章节（💔） | 6-8章 | 每5-6章一次 |
| 对话章节（💬） | 8-10章 | 每4-5章一次 |

**禁止**：连续3章同类型（避免单调）

## 五、伏笔设计系统

### 伏笔三级体系

| 级别 | 作用范围 | 首次出现 | 揭示时机 | 数量建议 |
|------|----------|----------|----------|----------|
| **主线伏笔** | 贯穿全书 | 第1-3章 | 第5-6卷 | 3-5个 |
| **卷级伏笔** | 贯穿单卷 | 卷首 | 卷末 | 每卷2-3个 |
| **章级伏笔** | 3-5章内回收 | 任意 | 3-5章后 | 按需设置 |

### 伏笔设计模板

```markdown
### 伏笔：[伏笔名称]

**首次出现**
- 章节：第[X]章
- 形式：[物品/对话/场景细节/背景信息]
- 内容：[具体描述，要足够隐蔽]

**中期强化**（可选）
- 章节：第[X]章
- 方式：[再次提及/相关线索/角色反应]

**揭示时机**
- 章节：第[X]章/第[X]卷
- 揭示方式：[直接揭示/角色发现/事件触发]
- 揭示效果：[对剧情/人物/世界观的影响]

**作用**
- 剧情作用：[推动什么情节]
- 人物作用：[揭示什么人物特质]
- 情感作用：[制造什么情感效果]
```

### 伏笔密度控制

- **前10章**：每章至少1个伏笔（建立悬念网）
- **10章后**：每章至少0.5个伏笔（维持悬念感）
- **单一伏笔**：每章最多出现3次（避免堆砌）

## 六、章间衔接设计

### 钩子-回应机制

| 前章钩子类型 | 本章开头必须回应 | 下章要求 |
|-------------|-----------------|---------|
| **A. 动作悬念** | 时间衔接 + 状态衔接 + 动作完成 | 必须配衔接段落 |
| **B. 信息悬念** | 信息处理 + 决策/反应 | 需回应信息 |
| **C. 情感悬念** | 情感延续 + 行动转化 | 需延续情感 |
| **D. 弱钩子** | 自然过渡 | 无需特别回应 |
| **E. 无钩子** | 直接进入 | 自然过渡 |

### 时间线管理

**每章必须包含**：
- 至少3个明确时间点（绝对或相对）
- 时间流逝的明确标记

**时间跳跃处理**：
```markdown
### timeline_continuity
- time_gap: [如：3天后/过了2小时]
- location_change: [如：从A地到B地]
- has_transition: true/false
- transition_summary: [过渡情节描述]
```

## 十一、浓缩包详细规范

浓缩包（Chapter Package）是跨章衔接的核心数据结构，每章必须维护以下10个模块：

### 1. chapter_start_state（本章起始状态）
```json
{
  "location": "具体地点名称",
  "time": "相对时间（如：灾变第X天 14:00）",
  "character_state": "主角当前身体/心理状态摘要"
}
```

### 2. chapter_end_state（本章结束状态）
```json
{
  "location": "具体地点名称",
  "time": "相对时间",
  "character_state": "主角状态变化",
  "key_items": ["关键物品1", "关键物品2"],
  "emotional_state": "本章结束时的情绪状态"
}
```

### 3. character_registry（角色登记）
```json
[
  {
    "name": "角色名",
    "status": "当前状态（健康/受伤/死亡/失踪）",
    "location": "当前位置",
    "relationship_change": "与主角关系变化（如有）"
  }
]
```

### 4. location_registry（地点登记）
```json
[
  {
    "name": "地点名",
    "description": "简要描述",
    "significance": "叙事功能（安全区/危险区/转折点）",
    "first_appearance": "首次出现章节"
  }
]
```

### 5. active_subplots（活跃支线）
```json
[
  {
    "name": "支线名称",
    "status": "进行中/已解决/已中断",
    "progress": "当前进度（0-100%）",
    "related_characters": ["相关角色"]
  }
]
```

### 6. physical_anchor_items（物象载体）
```json
[
  {
    "name": "物品名",
    "location": "当前位置（谁持有/在哪里）",
    "significance": "情感/剧情功能",
    "status": "完好/损坏/丢失"
  }
]
```

### 7. hook_history（钩子历史）
```json
[
  {
    "chapter": "第X章",
    "type": "A/B/C/D/E",
    "content": "钩子内容摘要",
    "resolved": true/false
  }
]
```

### 8. emotional_beats（情绪节拍）
```json
[
  {
    "chapter": "第X章",
    "emotion": "主导情绪（紧张/希望/悲伤等）",
    "intensity": "强度（1-10）",
    "trigger": "触发事件"
  }
]
```

### 9. foreshadowing_status（伏笔状态）
```json
[
  {
    "name": "伏笔名称",
    "status": "已埋伏/已强化/已揭示/已回收",
    "chapter": "当前状态所在章节",
    "significance": "剧情作用"
  }
]
```

### 10. timeline_notes（时间线备注）
```json
[
  {
    "event": "事件描述",
    "time": "相对时间",
    "significance": "对主线的影响"
  }
]
```

### 使用规范

1. **每章必须更新**：chapter_start_state 和 chapter_end_state
2. **有变化才更新**：character_registry、location_registry 等
3. **跨章衔接检查**：写作前检查前章的 chapter_end_state
4. **伏笔追踪**：foreshadowing_status 必须实时更新
5. **时间一致性**：timeline_notes 用于检查时间线逻辑

## 十二、跨卷管理（长篇专用）

### 全书伏笔总表

| 伏笔名称 | 级别 | 首次出现 | 揭示时机 | 当前状态 |
|---------|------|----------|----------|----------|
| [伏笔1] | 主线 | 第X卷第X章 | 第X卷第X章 | 已埋伏/已强化/已揭示 |
| [伏笔2] | 卷级 | 第X卷第X章 | 第X卷第X章 | 已埋伏/已强化/已揭示 |

### 人物弧光跨卷连续性

每卷结束时检查：
- [ ] 主角弧光是否按计划推进
- [ ] 关键配角是否有变化
- [ ] 反派动机是否合理
- [ ] 新角色引入是否有必要

### 设定一致性维护

**关键设定变更记录**：

| 变更项 | 原设定 | 新设定 | 变更原因 | 涉及章节 |
|--------|--------|--------|----------|----------|
| [设定名] | [原内容] | [新内容] | [原因] | [需修改的章节] |

### 前情提要生成

每卷开头的总结模板：
```markdown
## 第X卷 前情提要
```
