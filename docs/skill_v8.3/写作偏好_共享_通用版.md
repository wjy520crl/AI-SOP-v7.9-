# 写作偏好（共享）通用版 v1.0

> 通用版：适用于任何小说创作项目。主笔、台词、质检三个 Agent 共用。每次创作/优化/审稿前必读。

> v1.0 变更说明：
> - 角色体系改为通用模板（[主角]/[配角1]/[配角2]/[配角3]）
> - 「不是...是...」约束升级为 **零容忍（0处/章）**，v8.1 硬约束
> - 世界观一致性检查（通用）
> - 新增 v8.1 六条规则（R1-R6）
> - 意象域改为通用四域指导
> - 角色台词底色改为通用模板
> - 新增禁止事项：角色不得拥有超出设定的知识

## 一、文笔五律（核心）

### 节奏（Burstiness）
- 短句为主，长短穿插。一句话只讲一件事。
- **句式必须波动。** 禁止连续 3 句同长度（全是短句→像剁肉；全是长句→像念经）。刻意制造突变：一段平滑叙述后突然砸一个 3 字短句。
- 段落 ≤5 行（手机屏）。拒绝大段密排。
- 动作用短句推进，心理穿插在行动中。
- **句子长度分布参考**：短句（≤15字）占 40-50%，中句（15-30字）占 30-40%，长句（>30字）占 10-20%。拒绝全篇均匀分布。

### 逻辑
- 观点前置。先出结论再展开。不跳步不绕弯。
- 人物做一件事的原因，在行动前或行动中自然交代——不事后解释。
- 因果链清晰，读者不需要回头再读。

### 语言
- 用词干净。不浮夸形容词、不强行煽情、不网络烂梗。
- 语感温和平等，不居高临下说教。
- **"不是...是..."硬约束：全章 0 处。零容忍。禁止任何形式的"不是...而是...""并非...而是..."对比句式。**（v8.1 硬约束，比 EVE 版更严格）
- **检测方法（强制）：全量 grep "不是" → 人工逐条判断是否为对比句 → 报告精确行号。发现 1 处即返工。禁止肉眼扫读（已验证漏检率~50%）。注意变体：「不是很」「不是...是因为...」「并非...」等同属此约束。**

### 多样性（Perplexity）
- **词汇不可预测。** 避免同一段内重复同一个关键词/动词（如连续三句用"看"→换"扫/瞥/盯/打量"）。同一个意思换不同方式说。
- **拒绝平滑感。** AI 文章的通病是"每句话都合理，每段都顺畅，读完全忘光"。好的写作要偶尔让读者磕一下——一个不常见的比喻、一个突然的短句截断、一个出人意料但准确的动词。
- **信息密度波动。** 不是每段都要 300 字信息增量——有的段落就是放空的，有的是高强度。松→紧→松→紧，制造阅读节奏。全是紧的 = 累；全是松的 = 水。

### 情绪
- 共情 > 批判。先理解角色再写反应。
- 留白——不把感受说死，留一点让读者自己品。
- 情绪曲线：铺垫→蓄力→爆发→余韵。

## 二、番茄铁律

| # | 铁律 |
|---|------|
| 1 | 每 ~300 字必须有信息增量/冲突/反转 |
| 2 | 章末必须留钩子（悬念/反转/情绪，至少占一个） |
| 3 | 情绪曲线完整：铺垫→蓄力→爆发→余韵 |
| 4 | 利用信息差：读者知道 ≠ 角色知道 |
| 5 | 角色说话语气差异：每个角色应有独特的说话方式和语言习惯 |
| 6 | **角色台词职业底色**：每个角色的日常对话必须反映其背景训练——不是'贴标签式口癖'，而是'思维习惯渗透在语言里' |

---

### 角色台词底色

**不是'贴标签式口癖'，而是'思维习惯渗透在语言里'。**

每个角色的日常对话、哪怕是闲聊，都应该带有其背景训练的底色。不是加几句口头禅，而是说话方式本身反映了长期的习惯。

| 角色 | 背景 | 台词底色 | 具体表现 | 典型示例 |
|:---|:---|:---|:---|:---|
| **[主角]** | [主角背景设定] | [底色关键词] | [说话方式描述：话多/话少/行动优先/分析优先等] | "[示例台词1]" / "[示例台词2]" |
| **[配角1]** | [配角1背景设定] | [底色关键词] | [说话方式描述] | "[示例台词1]" / "[示例台词2]" |
| **[配角2]** | [配角2背景设定] | [底色关键词] | [说话方式描述] | "[示例台词1]" / "[示例台词2]" |
| **[配角3]** | [配角3背景设定] | [底色关键词] | [说话方式描述] | "[示例台词1]" / "[示例台词2]" |

**填写说明**：
- "背景"栏填写角色的职业、经历、性格等核心设定
- "台词底色"栏用2-4个关键词概括说话风格（如"极简克制""话多实在""军人命令式""逻辑优先"等）
- "具体表现"栏描述说话方式的具体特征（如话少、用短句、先说结论、情绪外露等）
- "典型示例"栏提供1-2个能体现角色语言特色的台词样本

**反面教材**：
- [错误示例]：角色说话方式与设定不符，所有角色说话同质化
- [正确示例]：挡住名字，只靠说话方式，读者能猜出是哪个角色

**写作自查**：写完一段角色对话后问自己——这段话挡住名字，**只靠说话方式**，读者能猜出是谁吗？猜不出 → 改。

## 三、写作手法

- 多写身体感受——渴、累、手磨破、泥土腥味、木板扎手、后背贴墙的凉意
- 主角可以有"无效时刻"——走神、发呆、注意到没意义的东西
- 人物可以说废话、话说一半被打断
- 加一两个"没用但鲜活"的细节
- 内心独白不要写成分析报告
- 对话：打断、欲言又止；潜台词 > 台词
- **体感优先**：写动作时写重量感、写环境时写气味质感、写物品时写触感（不是抽象形容词，是具体什么感受）

## 四、禁止事项

| ❌ | ✅ |
|----|----|
| AI 收束式结尾（模式库见下方「五、AI味禁区」） | 用具体动作或物件收尾 |
| 排比句收束段落 | 用单一细节锚定 |
| 过度解码人物心理 | 行动和对话传递心理 |
| 金句化说教 | 角色用自己的话表达 |
| 逻辑链过整 | 留一步让读者补 |
| "不是...是..."（任何数量） | **零容忍，0 处。全章禁止。** |
| meta梗/打破第四面墙 | 用剧情内单位替代元叙事 |
| 角色拥有超出设定的知识 | 角色只能知道其设定范围内应有的知识，不得"开天眼" |

---

### 第四面墙详解
角色**绝对不知道**自己在小说里、在第几章、读者是谁。

| ❌ meta梗（出戏） | ✅ 替代写法 |
|:---|:---|
| "他撑了九章" | "他撑了九天" / "跟了我们九波" |
| "这是第一卷的高潮" | "这一波比之前的都猛" |
| "系统升级了"（角色口吻像玩家） | "那个声音又响了。规则变了。" |
| "这章没完" | （删掉） |
| "读者看到这里应该明白了" | （删掉，让读者自己品） |

## 五、AI味七大禁区

> 来源：B站AI写作教学视频（2026-03-19发布，1601收藏）的实战验证结论。
> AI生成文本的七大典型缺陷。每一条都有明确的识别特征和替代方案。**写的时候主动避开，比事后润色高效10倍。**

### 1. 陈词滥调 —— 禁止高频模板化表达

AI从网文训练数据中高频调用的固定短语。偶尔出现可接受，密集出现 = AI味。

| ❌ 典型陈词滥调 | ✅ 替代方向 |
|:---|:---|
| 「指节因用力而发白」 | 写具体动作，别写抽象反应（"他攥紧铁锹，没松"） |
| 「嘴里涌出一股铁锈味儿」 | 换一个具体的、你角色真实会有的感受 |
| 「眼神冷得像冰」 | 别用"眼神"做载体——用行为传递冷（"他没看尸体。直接绕过"） |
| 「嘴角勾起一抹XX的弧度」 | 全删。这是AI味第一名。换一个微表情或不写 |
| 「洗得发白的XX」 | 换一个具体的磨损痕迹（"袖口磨出了线头，第三颗扣子颜色不一样"） |

**核心原则：如果你在别的网文里见过这个短语超过3次 → 不要用。**

### 2. 逻辑连接词 —— 禁止书面化过渡词

网络小说不是议论文。人类作者用动作、对话、时间推进来衔接——不用"第一、首先、其次"。

| ❌ 禁止使用 | ✅ 替代方式 |
|:---|:---|
| 「第一...第二...第三...」 | 拆成三个动作段落，中间用时间推进分割 |
| 「首先...其次...最后...」 | 同上 |
| 「综上所述」「总而言之」「换言之」 | 删。不需要。 |
| 「一方面...另一方面...」 | 一个人物用行动做一方面，另一个人物用反应做另一方面 |
| 「由此可见」「不难发现」 | 读者自己会发现。不要替他总结。 |

**grep自查**：`grep -E "第一|首先|其次|综上所述|总而言之|换言之|一方面|另一方面|由此可见|不难发现"`

### 3. 形容词与比喻堆砌 —— 单个主体 ≤ 3 个形容词

| ❌ 堆砌 | ✅ 节制 |
|:---|:---|
| 「发疯的、着了魔似的、红着眼睛向外跑去」 | 「他冲了出去。没回头。」 |
| 顿号并列三个以上形容词 | 删到 1-2 个，或用一个动作替代 |
| 破折号补充解释 | 删。让前面的描写自己说话——不需要解释 |
| 通篇"XX像XX"式比喻句 | 宁可不用比喻，别用烂比喻。每千字比喻 ≤ 1.5 处（v8.1 R1） |

**自查法**：随机抽 3 段，扫一眼是否有"顿号三连形容词"或"像"字比喻句。

### 4. 刻板化描写 —— 拒绝固定印象模板

AI学到的是"平均值"——一个角色/场景在AI眼里等于训练数据里最常见的版本。

| ❌ 刻板模板 | ✅ 破模板 |
|:---|:---|
| 「洗得发白的校服」（穷学生模板） | 写一个你**看见**的具体细节，不是从数据库调的 |
| 「苍白的脸，瘦弱的身影」（病弱模板） | 同上——这个角色具体哪里不一样？ |
| 「眼神坚定」「目光如炬」 | 别写眼神。写他做了什么。 |
| 「嘴角勾起一抹弧度」 | 再次强调：这是AI味第一名。删。 |

**核心原则：如果你没**亲眼**见过这个细节在你的角色身上——别写。宁可省略，不要填模板。**

### 5. 细节过度与留白缺失 —— 不写满，留缝隙

AI倾向于把能描写的东西全描写一遍。人类作者知道哪里该留。

| ❌ 过度细节 | ✅ 留白 |
|:---|:---|
| 描写覆盖场景里"每一个角落" | 写 2-3 个有叙事功能的东西。其余的读者自己补。 |
| 每进入新空间必描述环境 | 有时候一句"这间屋子比上一间大"就够了。 |
| 人物出场必写外貌穿着 | 只有这个角色**有叙事意义**时才写外貌。 |
| 动作每一步都写满 | 跳步。读者会脑补中间。 |

**留白 = 想象空间。填满 = 把读者推出去。**

### 6. 清单式无焦点描写 —— 禁止扫描式并列描摹

AI最常见的画面感崩坏：镜头像监控摄像头一样从左到右扫描，每个人都写"穿着+动作"。

| ❌ 清单式 | ✅ 有焦点 |
|:---|:---|
| 「张三穿黑夹克在擦枪，李四穿灰T恤在吃东西，王五穿...」 | 只聚焦 1-2 个有叙事意义的人。其余人"角落里有几个身影"一笔带过 |
| 进入群像场景→开始逐个扫描 | 先锚定一个焦点人物（通常是主角在看的那个人），通过他的视角展开 |
| 并列描摹无主次 | 必须有叙事重心——读者眼睛该看谁、该忽略谁 |

**自查法**：群像场景里，如果出现连续三个以上"XX（人名）在XX（动作）"式的并列描述 → 删到 1-2 个，其余合并/省略。

### 7. 情绪直白陈述与空洞结尾

| 子项 | ❌ | ✅ |
|:---|:---|:---|
| 情绪直白 | 「他很伤心」「她很愤怒」 | 用动作、环境、身体反应间接传递（见文笔五律·情绪律） |
| 空洞结尾 | 「这一切才刚刚开始」「他不知道的是...」「或许...也或许...」 | 用具体动作或物件收尾（见禁止事项） |

**AI收束结尾完整模式库**（发现新模式→追加到此处）：
- 「他知道...」 / 「他不知道的是...」
- 「从此刻起...」 / 「新的XX开始了」
- 「这一切才刚刚开始」
- 「或许...也或许...」
- 情感总结句（「这是他第一次感到真正的XX」）
- 排比收束（「有的...有的...还有的...」三连）

## 六、硬核六条 + v8.1 新增规则

> 规则来源：用户创作经验总结 + v8.1 版本迭代。
> 定位：结构健康与叙事逻辑层约束。与五律（文本质感）和七禁区（AI味防控）互补，形成三层质量防线。
> **违反任一条 = 一票否决，直接退回重写。**

### 1. 细节必须有用
**所有景物、动作、物件描写，必须对剧情/人设/伏笔有作用。**

| ❌ 无效闲笔 | ✅ 功能化细节 |
|:---|:---|
| 「窗外飘着细雨，街灯昏黄」——仅营造氛围，无叙事功能 | 删。或改写为有叙事意义的细节（如「雨打在铁皮屋顶上。[主角名]看了眼——防水布要换」） |
| 对剧情/人设/伏笔无任何推进的环境描写 | 删。留白让读者补。 |
| 纯粹装饰性形容词/比喻 | 每个描写都必须能回答「删掉它会丢什么信息」——答不上来 → 删 |

**自查法**：写完每段环境/物件描写后问——这段描写如果删掉，读者会错过什么？答不上来 → 删。

### 2. 角色锁定
**固定角色不许增减，绝不凭空客串无关配角。每人台词有专属语感，不能同质化。**

| ❌ 违规 | ✅ 合规 |
|:---|:---|
| 临时拉一个「路人」「邻居大妈」来说一句无关台词 | 删。让既定角色完成这个功能。 |
| 每个角色台词必须有辨识度——挡住名字也能猜出谁在说话 | |
| 新增配角只为「推剧情」一次性使用 | 剧情推进只能由既定角色完成。新角色 = 新人格弧线 = 必须长期存在。 |

### 3. 杜绝空降结论
**人物所有猜测、判定、揭秘，都要有可见细节做依据。**

| ❌ 空降 | ✅ 有据 |
|:---|:---|
| 「[主角名]一眼就看出那东西有问题」——没说看到了什么特征 | 写出他看到的：颜色不对、速度异常、表面纹路 |
| 「[配角名]判断今晚会有大麻烦」——没写判断依据 | 写出他注意到的异常：远处的声音变了、空气里的味道更浓了、上一次的间隔比平时短 |
| 角色突然「明白了」某件事，但读者没看到推理过程 | 线索必须在之前场景出现过（可见细节），不能事后补充 |

**核心原则**：读者必须能和角色同步推理。如果读者看到揭秘时感觉「你怎么知道的」→ 空降结论，返工。

### 4. 杜绝体感重复
**杜绝同一句式、同一体感机械重复。不用大段内心旁白，情绪只靠动作、眼神、对话流露。**

| ❌ 重复 | ✅ 波动 |
|:---|:---|
| 连续两段用同一种身体感受（如连续写「疼」「酸」「麻」同一部位） | 换部位、换感官类型、或跳过一段不写感受 |
| 同一章内多次出现「他感到XX」「他觉得XX」的内省句式 | 全改动作/眼神/对话。「他感到紧张」→「他把铁锹攥紧了一圈。没松。」 |
| 大段内心旁白（超过3行的心理叙述） | 拆成动作碎片。或删。 |

**与五律·节奏律的关系**：节奏律管句式长短波动，本条规定的是**体感类型/内省模式不能重复**——是节奏律的上层补充。

### 5. 拒绝模板化结构
**剧情推进自然，不按模板流水线走流程。不强行凑固定套路。**

| ❌ 模板套路 | ✅ 破模板 |
|:---|:---|
| 每章必出现「系统提示/关键事件」环节 | 关键事件需要有充分的剧情必要性。非必要 → 跳过，用一句带过。 |
| 同一推进方式反复使用（发现→应对→总结→再发现） | 推进方式只在关键节点使用。章与章之间用人物决策/冲突推进，不用单一链条。 |
| 同一类型高潮作为每章固定模式 | 高潮只在关键节点出现。平时用人物互动/资源紧缺/心理压力推进。 |
| 章结构雷同（开篇写景→对话推进→关键事件→高潮→终局） | 每章节奏型应该不同。有的章从对话开篇，有的从动作，有的从静默。 |

### 6. 克制白描
**不刻意堆文艺辞藻，不刻意渲染空洞氛围。**

| ❌ 文艺腔 | ✅ 克制 |
|:---|:---|
| 「暮色如血，将整座废弃的城市浸染成一片悲怆的橙红」 | 「天暗了。西边的火烧云映在碎玻璃上，红得刺眼。」 |
| 氛围渲染段落（纯写景/写情绪，无叙事推进） | 删。氛围从动作和对话里渗出来，不要单独端上来。 |
| 「XX像XX一样XX」式文艺比喻（非功能性比喻） | 删。功能性比喻（帮助理解复杂概念）保留。装饰性比喻全删。 |

**与五律·语言律的关系**：语言律管「不浮夸形容词」，本条进一步约束**整个段落的写作姿态**——不端着写，不刻意营造。

### v8.1 新增规则（R1-R6）

> 以下六条为 v8.1 版本新增硬约束，与上方硬核六条并列执行。

#### R1 比喻密度 ≤1.5处/千字
- 全章比喻句（含"像""仿佛""犹如""好似"等）总数 ÷ 千字数 ≤ 1.5
- **grep 自查**：`grep -nE "像|仿佛|犹如|好似|如同|似的" 章节文件`
- 超标 → 逐条评估，删除非功能性比喻，保留帮助理解的核心比喻

#### R2 解释性插入零容忍
- 禁止在叙述中插入解释性内容（括号补充、破折号解释、"也就是说""换句话说"等）
- 读者应该通过上下文理解，不需要作者跳出来解释
- **例外**：角色对话中自然出现的解释可以保留（如角色向另一角色解释某事物的功能）

#### R3 开篇200字规则
- 章节开篇 200 字内必须有：行动/对话/冲突，至少占一个
- 禁止开篇 200 字纯环境描写、纯内心独白、纯系统提示
- 目的：前 200 字决定读者是否继续阅读，必须有抓手

#### R4 "某种/一种"禁用
- 禁止使用「某种」「一种」作为模糊修饰（如「某种不安」「一种奇怪的感觉」）
- 要么写清楚具体是什么，要么不写
- **grep 自查**：`grep -nE "某种|一种" 章节文件`
- 发现 → 替换为具体描写或删除

#### R5 体感重复 ≤3次/章
- 同一种身体感受（如"疼""累""饿""冷"）在同一章内出现不超过 3 次
- 同一部位的同一体感不超过 2 次
- 超标 → 换感官类型（视觉→听觉→触觉→嗅觉）或合并为一次更深入的描写

#### R6 grep 自检流程
- 每章写完后，必须执行以下 grep 自检，结果附在文末：
  1. `grep -n "不是"` → 检查"不是...是..."对比句（应为 0 处）
  2. `grep -nE "像|仿佛|犹如|好似|如同|似的"` → 检查比喻密度
  3. `grep -nE "某种|一种"` → 检查模糊修饰
  4. `grep -nE "第一|首先|其次|综上所述|总而言之|换言之"` → 检查逻辑连接词
  5. `grep -nE "他知道|他不知道|从此刻起|新的.*开始|这一切才刚刚|或许.*或许"` → 检查 AI 收束结尾
- 任一 grep 发现问题 → 修改后重新检查

## 七、质检专用

### 硬约束（一票否决，任一条不通过直接退回）

| # | 检查项 | 判定标准 |
|---|--------|----------|
| 1 | 「不是...是...」计数 | **0 处。零容忍。** 列出行号。**必须 grep+人工，禁止肉眼扫读。**变体包括「不是很」「不是...是因为...」「并非...」等。发现 1 处即返工。 |
| 2 | 章末钩子 | 悬念/反转/情绪，至少占一个。无 → 返工 |
| 3 | AI 收束式结尾 | 无以下任一模式（模式库见「五、AI味七大禁区→7」）：「他知道...」「他不知道的是...」「从此刻起...」「新的XX开始了」「这一切才刚刚开始」「或许...也或许...」、情感总结句、排比收束 |
| 4 | **世界观一致性** | 世界观设定正确，无自相矛盾。所有设定（力量体系/社会规则/角色能力/环境规则等）与已建立设定一致 |
| 5 | 大纲对照 | 无重大偏离（情节走向/人物出场/关键事件） |
| 6 | **v8.1 规则合规** | R1 比喻密度 ≤1.5处/千字；R2 解释性插入 0 处；R3 开篇 200 字有抓手；R4 "某种/一种" 0 处；R5 体感重复 ≤3次/章；R6 grep 自检已执行 |

### 柔性检查（打分项，不通过不退回但扣分）

| # | 检查项 | 判定标准 |
|---|--------|----------|
| 7 | 段落密度 | 抽样 10 段，超 5 行 ≤ 2 段 |
| 7b | 句式波动 | 连续 3 句同长度（全短/全中/全长）≤ 2 处。全篇短句占比 40-50% |
| 7c | 逻辑连接词（AI味） | 无「第一/首先/其次/综上所述/总而言之/换言之/一方面/另一方面/由此可见/不难发现」。**grep检测** |
| 7d | 清单式描摹（AI味） | 无连续 3 个以上「人名+穿着+动作」式并列扫描。群像场景有叙事焦点 |
| 7e | 形容词堆砌（AI味） | 随机抽 3 段，单个主体 ≥4 个形容词修饰 → 扣分。比喻句每千字 ≤ 1.5 处 |
| 8 | 信息密度 | 每 ~300 字有信息增量/冲突/反转。连续两段无 → 扣分 |
| 9 | 情绪曲线 | 完整四段：铺垫→蓄力→爆发→余韵 |
| 10 | 信息差 | 读者知道 ≠ 角色知道，至少 1 处 |
| 11 | 身体感受 | ≥ 5 处（渴/累/磨破/泥土腥味/木板扎手/后背贴墙凉意等）。最低红线。优秀线 ≥ 8 处 |
| 12 | 对话质量 | 打断 ≥ 1 处 / 欲言又止 ≥ 1 处 / 潜台词 > 明台词 |
| 13 | 排比收束 | 无排比句收束段落 |
| 14 | 过度解码 | 无替读者总结人物心理（用行动和对话传递） |
| 15 | 金句说教 | 无说教式金句（角色可以有自己的看法，但不是"输出道理"） |

### 评分（10 分制）

**及格线：9分。** 硬约束全通过 + 评分 ≥ 9 → 通过；评分 < 9 → 不通过，需修改后重新提交。

| 维度 | 权重 | 覆盖检查项 |
|------|------|-----------|
| 节奏 | 20% | 信息密度/冲突反转/钩子/段落控制（#2 #8 #10） |
| 人物 | 20% | 语气差异/人设一致/对话质量/生理细节（#7 #12） |
| 氛围 | 15% | 意象域统一/感官覆盖/环境描写（#7b #9 #11） |
| 设定 | 15% | 世界观设定一致性（#4） |
| 文笔 | 15% | 句式波动/语言多样性/比喻密度/形容词控制（#7 #7d #7e） |
| 悬念 | 15% | 章末钩子/信息差/情绪曲线（#2 #8） |

### 附：意象四域（通用指导）

> 写作时优先从以下四个意象域中取材，保持全篇感官一致性。
> 以下为通用示例，实际项目应根据世界观设定替换具体内容。

| 域 | 核心意象 | 典型细节（示例） |
|:---|:---|:---|
| **生机/衰败** | 生长 vs 衰亡 | [根据世界观设定填写：如植物生长的声音、叶片舒展的触感、腐朽物质的气味、泥土翻动时的气息] |
| **光/暗** | 昼夜节律、明暗对比 | [如阳光被遮挡时的光晕、夜晚月光下的剪影、手电筒光柱里的灰尘、黎明前最暗的那几分钟] |
| **压力/重量** | 物理存在感、压迫感 | [如重物压肩膀的钝痛、门关上时的震动、墙缝里渗出的灰尘、堆叠物品的吱嘎声] |
| **温度/感官** | 身体性感受 | [如汗水蛰伤口的刺痛、冬天握工具时手指失去知觉、特殊环境下的气味、连续不睡觉时太阳穴的跳痛] |

**使用说明**：
- 每个项目应根据自己的世界观设定，替换四个域中的"核心意象"和"典型细节"
- 保持全篇在同一场景内使用同一主导意象域
- 禁止跨域比喻（如压力/重量域的场景中突然使用生机/衰败域的比喻）
