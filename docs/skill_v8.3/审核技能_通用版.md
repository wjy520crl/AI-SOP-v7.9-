## 五、评分标准（10分制）

**及格线：9分**

### 权重分布
| 维度 | 权重 | 覆盖检查项 |
|------|------|-----------|
| 节奏 | 20% | #2 #8 #10 |
| 人物 | 20% | #7 #12 |
| 氛围 | 15% | #7b #9 #11 |
| 设定 | 15% | #4 |
| 文笔 | 15% | #7 #7d #7e |
| 悬念 | 15% | #2 #8 |

### 评分等级
| 分数 | 等级 | 处理 |
|------|------|------|
| 9.5+ | 优秀 | 通过，进入下一章 |
| 9.0-9.4 | 良好 | 小修后通过 |
| 8.5-8.9 | 合格 | 修改后重检 |
| 8.0-8.4 | 待改进 | 修改后重检 |
| <8.0 | 不合格 | 建议重写 |

## 六、质检输出格式

```
【质检结论】通过 / 不通过
【评分】X/10

【硬约束检查】
  1. 「不是...是...」：X 处（行号：Lxx）通过/不通过
  2. 章末钩子：有/无 通过/不通过
  3. AI 收束结尾：无/有（行号：Lxx）通过/不通过
  4. 世界观一致性：零违规/X 处违规 通过/不通过
  5. 大纲对照：无偏离/X 处偏离 通过/不通过
  6. v8.1 规则合规：
     R1 比喻密度：X处/千字 通过/不通过
     R2 解释性插入：X 处 通过/不通过
     R3 开篇200字：有/无抓手 通过/不通过
     R4 "某种/一种"：X 处 通过/不通过
     R5 体感重复：X 次/章 通过/不通过
     R6 grep自检：已执行/未执行 通过/不通过

【柔性检查】
  7. 段落密度：超5行 X/10 段
  7b. 句式波动：连续同长 X 处
  7c. 逻辑连接词：有/无
  7d. 清单式描摹：有/无
  7e. 形容词堆砌：X 处
  8. 信息密度：连续无增量 X 处
  9. 情绪曲线：完整/缺失
  10. 信息差：X 处
  11. 身体感受：X 处
  12. 对话质量：打断X/欲言又止X
  13. 排比收束：无/有
  14. 过度解码：无/有

【必须修改项】（不通过时列出，含行号和修改方向）
  1. ...

【优化建议】（可选）
  1. ...
```

## 七、章间衔接检查

### 前章钩子类型识别
| 类型 | 定义 | 本章开头必须包含 |
|------|------|-----------------|
| **A. 动作悬念** | 未完成动作 | 时间衔接 + 状态衔接 + 动作完成 |
| **B. 信息悬念** | 新发现/线索 | 信息处理 + 决策/反应 |
| **C. 情感悬念** | 内心波动 | 情感延续 + 行动转化 |

### 检查项
- [ ] 前章钩子类型已识别
- [ ] 本章前200字已回应
- [ ] 时间衔接明确
- [ ] 状态衔接明确

## 九、质量门控速查

| 门控 | 标准 | 不通过处理 |
|:---|:---|:---|
| 硬约束扫描 | 0处违规 | 修改后重新扫描 |
| grep自检 | 全部通过 | 逐项修改 |
| 章间衔接 | 3项通过 | 重写开篇200字 |
| 比喻密度 | ≤5处/3000字 | 删除冗余比喻 |
| 体感重复 | 每种≤3次 | 用替换表变体 |
| 浓缩包完整性 | 10个模块 | 补充缺失模块 |
| 开篇200字 | 有抓手 | 重写开篇 |
| 时间锚点 | ≥3处 | 补充时间标记 |

## 十、质检流程

```
Step 1: 正则扫描器（格式检查）
  → 不通过：直接打回修改
  → 通过：进入Step 2

Step 2: 大模型质检（质量评估）
  → 输出评分 + 优化建议

Step 3: 评分判定
  → ≥9.5：通过，进入下一章
  → <9.5：进入Step 4

Step 4: 根据建议修改
  → 回到Step 1重新扫描

循环上限：5轮
```
