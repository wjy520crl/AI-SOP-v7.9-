## 一、绝对禁止列表（R0）

**零容忍，全文0处**

| # | 禁止项 | 说明 | 检测命令 |
|---|--------|------|----------|
| R0.1 | 「不是...是...」句式 | 包括"不是...而是...""并非...而是..."等所有对比句式 | `grep -n "不是"` |
| R0.2 | 冻结意象 | 嘴唇干裂、指节发白、嘴角勾起、倒吸一口凉气、空气凝固 | 人工检查 |
| R0.3 | AI收束式结尾 | "他知道...""从此刻起...""新的XX开始了"等 | `grep -nE "他知道|他不知道|从此刻起"` |
| R0.4 | 解释性插入 | "XX，不需要YY""XX，意味着YY" | 人工检查 |
| R0.5 | "某种/一种"模糊修饰 | 要么写具体，要么不写 | `grep -nE "某种|一种"` |
| R0.6 | 章间断裂 | 本章前200字未回应前章钩子 | 人工检查 |

## 二、写作规则（R1-R9）

### R1 比喻密度
- **标准**：≤1.5处/千字（3000字最多4-5个）
- **检测**：`grep -nE "像|仿佛|犹如|好似|如同|似的"`
- **超标处理**：删除冗余，保留最精准的1-2个

### R2 解释性插入
- **标准**：0处
- **形式**：括号补充、破折号解释、"也就是说"等
- **处理**：删掉意思不变的句子

### R3 开篇200字
- **标准**：必须包含前章回应 + 本章抓手
- **抓手类型**：动作/对话/冲突/关键事件（至少一个）
- **禁止**：纯环境描写开篇、纯内心独白开篇

### R4 "某种/一种"禁用
- **标准**：0处
- **处理**：写具体细节，或删除

### R5 体感重复
- **标准**：同一身体感受每章最多3次
- **处理**：使用替换表变体（见第五章）

### R6 主语省略
- **标准**：连续3个"[主角名]+动词"后，必须变化
- **变化方式**：省略主语 / 换"他" / 环境作主语

### R7 章间衔接
| 前章钩子类型 | 本章开头必须包含 |
|-------------|-----------------|
| A. 动作悬念 | 时间衔接 + 状态衔接 + 动作完成 |
| B. 信息悬念 | 信息处理 + 决策/反应 |
| C. 情感悬念 | 情感延续 + 行动转化 |

### R8 章末钩子
- **高潮/情感/对话章节**：A/B/C类型钩子
- **低潮章节**：D/E类型（弱钩子或无钩子）

### R9 时间锚点
- **标准**：每章至少3个明确时间点
- **形式**：绝对时间（14:00）或相对时间（3小时后）

## 三、AI味七大禁区

### 1. 陈词滥调
| ❌ 禁止 | ✅ 替换为 |
|:---|:---|
| 「指节因用力而发白」 | 写具体动作 |
| 「嘴角勾起一抹XX的弧度」 | **全删，AI味第一名** |
| 「眼神冷得像冰」 | 用行为传递冷 |
| 「洗得发白的XX」 | 写具体磨损痕迹 |

**原则**：在别的网文里见过超过3次 → 不要用。

### 2. 逻辑连接词
| ❌ 禁止 | ✅ 替换为 |
|:---|:---|
| 「第一...第二...第三...」 | 拆成动作段落 |
| 「首先...其次...最后...」 | 同上 |
| 「综上所述」「总而言之」 | 删 |

### 3. 形容词堆砌
- 单个主体 ≤ 2个形容词
- 每千字比喻 ≤ 1.5处

### 4. 刻板化描写
- 写你**看见**的具体细节，不是从数据库调的模板

### 5. 细节过度
- 写 2-3 个有叙事功能的东西，其余让读者自己补

### 6. 清单式描摹
- 群像场景只聚焦 1-2 人，其余一笔带过

### 7. 情绪直白
- 「他很伤心」→ 用动作、环境、身体反应间接传递

## 四、文笔五律

### 节奏（Burstiness）
- 短句为主，长短穿插。一句话只讲一件事。
- **句式必须波动。** 禁止连续3句同长度。
- 段落 ≤5行（手机屏）。
- **句子长度分布**：短句（≤15字）40-50%，中句（15-30字）30-40%，长句（>30字）10-20%。

### 逻辑
- 观点前置。先出结论再展开。
- 因果链清晰，读者不需要回头再读。

### 语言
- 用词干净。不浮夸形容词、不强行煽情。
- **"不是...是..."硬约束：全章0处。**

### 多样性（Perplexity）
- **词汇不可预测。** 避免同一段内重复同一个关键词。
- **拒绝平滑感。** 偶尔让读者"磕一下"。
- **信息密度波动。** 松→紧→松→紧。

### 情绪
- 共情 > 批判。留白——不把感受说死。
- 情绪曲线：铺垫→蓄力→爆发→余韵。

## 五、替换表

### 5.1 情绪直通词替换

| 禁止 | 替换为 |
|-----|-------|
| 感到紧张 | 手指在XX上收紧 |
| 感到害怕 | 后退一步，后背抵着墙 |
| 感到疼痛 | 闷哼一声，咬住牙 |
| 意识到XX | （删掉） |
| 他知道... | （删掉，改为动作） |

### 5.2 沉默填充替换

| 禁止 | 替换为 |
|-----|-------|
| 安静了几秒 | [角色]把XX叠成方块，又展开 |
| 沉默在空气中蔓延 | 风从破洞灌进来 |
| 空气仿佛凝固了 | [角色]的呼吸声清晰可闻 |

### 5.3 体感重复替换

| 原始 | 变体1 | 变体2 | 变体3 |
|-----|-------|-------|-------|
| 伤口疼 | 传来撕裂感 | 在发烫 | 一跳一跳地疼 |
| 疲惫 | 手按住膝盖才站起来 | 眼皮往下沉 | 肩膀垮下来 |
| 寒冷 | 寒意从骨头缝里渗出来 | 手指冻得发僵 | 呼出的气白茫茫 |
| 紧张 | 喉咙发紧 | 手心出汗 | 心跳声很大 |

### 5.4 陈词滥调替换

| ❌ 陈词滥调 | ✅ 具体写法 |
|------------|------------|
| 指节因用力而发白 | 指节抵在桌面上，压出浅坑 |
| 眼神冷得像冰 | 目光扫过来，没有停留 |
| 洗得发白的衬衫 | 领口磨出毛边，袖口有线头 |
| 倒吸一口凉气 | 呼吸停了一瞬 |
| 空气仿佛凝固了 | 只有风扇在头顶转动的声音 |

## 六、番茄铁律

| # | 铁律 |
|---|------|
| 1 | 每 ~300 字必须有信息增量/冲突/反转 |
| 2 | 章末必须留钩子（悬念/反转/情绪，至少占一个） |
| 3 | 情绪曲线完整：铺垫→蓄力→爆发→余韵 |
| 4 | 利用信息差：读者知道 ≠ 角色知道 |
| 5 | 角色说话语气差异：每个角色应有独特的说话方式 |
| 6 | **角色台词职业底色**：每个角色的对话必须反映其背景训练 |

## 七、硬核六条

1. **细节必须有用**：所有描写必须对剧情/人设/伏笔有作用
2. **角色锁定**：固定角色不许增减，每人台词有专属语感
3. **杜绝空降结论**：所有猜测、判定都要有可见细节做依据
4. **杜绝体感重复**：同一体感每章最多3次，换部位或换感官类型
5. **拒绝模板化结构**：剧情推进自然，不按模板流水线走流程
6. **克制白描**：不刻意堆文艺辞藻，不刻意渲染空洞氛围

## 八、grep自检命令集

```bash
# R0.1 「不是...是...」检查（零容忍）
grep -n "不是" [章节文件]

# R1 比喻密度检查
grep -nE "像|仿佛|犹如|好似|如同|似的" [章节文件]

# R0.5/R4 模糊修饰检查（零容忍）
grep -nE "某种|一种" [章节文件]

# 逻辑连接词检查
grep -nE "第一|首先|其次|综上所述|总而言之|换言之" [章节文件]

# R0.3 AI收束结尾检查
grep -nE "他知道|他不知道|从此刻起|新的.*开始|这一切才刚刚|或许.*或许" [章节文件]

# 情绪直通词检查
grep -nE "感到|觉得|意识到|发现" [章节文件]

# 沉默填充检查
grep -nE "沉默|安静了|空气凝固" [章节文件]

# 形容词堆砌检查
grep -nE "的.*的.*的" [章节文件]
```

## 九、评分标准

### 正文质检
- **及格线：9.0分**
- **优秀：9.5分+**

| 分数 | 等级 | 处理 |
|------|------|------|
| 9.5+ | 优秀 | ✅ 通过，进入下一章 |
| 9.0-9.4 | 良好 | ⚠️ 小修后通过 |
| 8.5-8.9 | 合格 | ❌ 修改后重检 |
| <8.5 | 不合格 | ❌ 建议重写 |

### 大纲质检
- **及格线：9.5分**（结构问题修改成本低，标准更严）

## 十、章节类型标记

| 类型 | 标记 | 功能 | 钩子要求 |
|------|------|------|----------|
| **高潮章节** | 📍 | 推进情节 | A/B/C型强钩子 |
| **低潮章节** | 🌙 | 读者喘息 | D/E型弱钩子或无 |
| **情感章节** | 💔 | 深化人物 | C型情感钩子 |
| **对话章节** | 💬 | 推进关系 | B/C型钩子 |

### 钩子类型定义
- **A. 动作悬念**：未完成动作，停在关键时刻
- **B. 信息悬念**：新发现/线索，待解读
- **C. 情感悬念**：内心波动/决策点
- **D. 弱钩子**：状态定格，轻微悬念
- **E. 无钩子**：开放式结尾，自然收束
