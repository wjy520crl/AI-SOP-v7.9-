# 写作偏好（精简版）通用版 v1.0-lite

> 主笔必读。每次写章前加载。不含反面教材/版本历史，只留执行规则。
> 通用版：适用于任何小说创作项目。

## 一、文笔五律（执行级）

### 节奏
- 短句为主（≤15字占40-50%），长短穿插。禁止连续3句同长度。
- 段落≤5行。紧张用短句砸，松弛用长句铺。

### 语言
- 用词干净，不浮夸。
- **「不是...是...」0处/章（零容忍）**。无论口语还是对比句，一律清零。
- **grep "不是" 逐条自查**（肉眼漏检率50%）。
- **grep "某种\|一种" → 0处**。禁止模糊指代，写具体。

### 多样性
- 同一段动词不重复≥3次（看→扫/瞥/盯/打量）。
- 偶尔制造"磕"感：意外比喻、突然断句、反直觉动作。
- **比喻 ≤1.5处/千字**。宁可不比，不要硬比。

### 情绪
- 共情>批判。留白，不说死。

## 二、番茄铁律

| # | 铁律 |
|---|------|
| 1 | 每~300字必须有信息增量/冲突/反转 |
| 2 | 章末留钩子（悬念/反转/情绪，占一个） |
| 3 | 情绪曲线：铺垫→蓄力→爆发→余韵 |
| 4 | 利用信息差：读者知道≠角色知道 |
| 5 | 角色语气差异 |
| 6 | **开篇200字内必须含动作/对话/冲突/关键事件**，禁止纯环境起手 |

### 角色台词底色

| 角色 | 底色 | 示例 |
|:---|:---|:---|
| [主角] | [底色关键词，如：极简克制，话少行动派] | "[示例台词1]" "[示例台词2]" |
| [配角1] | [底色关键词，如：话多实在，偶尔冲动] | "[示例台词1]" "[示例台词2]" |
| [配角2] | [底色关键词，如：军人底色，简短命令式] | "[示例台词1]" "[示例台词2]" |
| [配角3] | [底色关键词，如：冷静分析型，逻辑优先] | "[示例台词1]" "[示例台词2]" |

**填写说明**：根据项目实际角色设定，填写每个角色的说话风格关键词和典型台词示例。挡住名字只靠说话方式，读者能猜出是谁。

## 三、禁止事项（一票否决）

| ❌ | 替代 |
|:---|:---|
| AI收束式结尾（他知道/从此刻起/新的XX开始） | 具体动作或物件收尾 |
| 排比收束 | 单一细节锚定 |
| 过度解码心理 | 行动和对话传递 |
| 金句说教 | 角色用自己的话 |
| 逻辑连接词（第一/首先/其次/综上所述） | 动作、时间推进 |
| 清单式描摹（连续3人并列描写） | 聚焦1-2人，其余一笔带过 |
| 形容词堆砌（单个主体≥4个） | 删到1-2个或换动作 |
| meta梗/打破第四面墙 | 用剧情内单位替代 |
| **角色拥有超出设定的知识** | 角色只能知道其设定范围内应有的知识 |
| 解释性插入（括号注释、旁白补设定） | 融入动作或对话 |

## 四、意象域（通用四域）

描写时优先从以下四域取材，保持世界观质感统一。
以下为通用示例，实际项目应根据世界观设定替换具体内容：

| 域 | 关键词/方向 |
|:---|:---|
| 生机/衰败 | [根据世界观设定填写：如枯叶、腐土、菌丝蔓延、根系断裂、苔藓、腐烂气味] |
| 光/暗 | [如阳光切割废墟、手电光柱中浮尘、月光下的阴影蠕动] |
| 压力/重量 | [如门板后的撞击、墙壁裂纹扩散、地基下沉感、物资压肩] |
| 温度/感官 | [如汗水蛰眼、铁锈味、指尖冻麻、胃部痉挛、耳鸣] |

## 五、展开策略（写够3000-3500字）

### 每个核心节拍至少 400-500 字
将大纲的 5 个节拍拆分，每个节拍独立展开。

### 战斗/冲突场景展开公式
至少 3 轮攻防交替：
```
① 发现/锁定（50字）→ ② 攻击/规避（100字）→ ③ 身体感受/环境变化（100字）
```
重复 3 轮 = 750 字，自动达标。

### 群像场景展开公式
≥3 人同时出场时，每人至少 1 句台词 + 1 个动作：
```
[主角]："X。" 手搭在门把上没拧。
[配角1]："Y！" 脖子上的青筋跳了一下。
[配角2]："Z。" 枪口朝下，拇指压在保险上。
```
6 人各 1 句 = 300 字 + 动作描写 = 500 字。

### 环境描写展开公式
每进入一个空间，写 2 个感官细节（从触觉/嗅觉/听觉/味觉选）：
```
① 嗅觉：发霉的窗帘混着铁锈味，像含了一枚旧硬币
② 触觉：门板震颤传到掌心，频率越来越密
③ 听觉：远处有什么东西在拖行，声音闷在墙壁里
```
每个空间 2 个细节 = 100 字。

### 对话展开公式
禁止连续 3 句纯对话。每段对话间插入动作或身体感受：
```
❌ "A。" "B。" "C。" （纯对话，干瘪）
✅ "A。" [主角]把最后一块木板钉上。"B。" [配角1]抹了把脸上的汗，指甲缝里全是泥。"C。" 门外又响了一下。
```
插入动作/感受 = 对话字数翻倍。

### 心理描写展开公式
禁止"他知道/她意识到/他明白"。改为动作碎片：
```
❌ 他感到一阵紧张。他知道门外的东西比昨天更多。
✅ 他把铁锹攥紧又松开。看了一眼门缝。然后走回去，把桌子又往前推了半米。
```
每个心理转变用 2-3 个动作替代 = 50 字。

## 六、硬约束速查（写完必跑）

```
grep "不是" → 0处（零容忍）
grep "某种\|一种" → 0处
比喻 ≤1.5处/千字
开篇200字内含动作/对话/冲突/关键事件
同一体感 ≤3次/章
解释性插入 0处
结尾不是"他知道"/"从此刻起"/"新的XX"
结尾有钩子（悬念/反转/情绪）
身体感受 ≥5处（优秀≥8）
对话有打断(≥1) + 欲言又止(≥1)
无"他知道/她意识到/他明白"式总结
grep "第一|首先|其次|综上所述|总而言之" → 零命中
无排比收束/说教金句
抽10段→超5行≤2段
无第四面墙突破
无角色拥有超出设定知识的表现
```

## 七、质检硬约束（调度者用）

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 「不是...是...」 | 0处，grep+人工 |
| 2 | 「某种/一种」 | 0处，grep |
| 3 | 章末钩子 | 悬念/反转/情绪，至少一个 |
| 4 | AI收束结尾 | 无模式库内任一 |
| 5 | 世界观一致性 | 设定无矛盾；意象域不偏离；无超出角色认知范围的知识 |
| 6 | 大纲对照 | 无重大偏离 |

**评分100分制**：文笔25 + 情节20 + 人物15 + 格式10 + 禁止15 + 世界观15
**及格线：90分。** 硬约束全通过 + 评分 ≥ 90 → 通过；评分 < 90 → 不通过，需修改后重新提交。

### 评分输出格式

```
【质检结论】通过/不通过
【评分】X/10
【硬约束】1-6项 通过/不通过 + 行号
【柔性】段落密度/句式波动/逻辑连接词/清单描摹/形容词堆砌/信息密度/情绪曲线/信息差/身体感受/对话质量/排比/过度解码/金句/比喻密度/体感重复/解释性插入
【修改项】（不通过时列出）
【优化建议】可选
```
