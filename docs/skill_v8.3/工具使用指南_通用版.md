# 工具使用指南（通用版）v1.0

> 本指南说明如何使用小说创作辅助工具脚本。

---

## 一、工具概述

### 可用工具

| 工具 | 文件名 | 功能 | 使用时机 |
|------|--------|------|----------|
| 通用扫描器 | sop_scanner_generic.py | 18维格式检查 | 每章写完后 |
| 增量检查器 | sop_scanner_v82_generic.py | 4项增量检查 | 扫描器通过后 |

### 工具 vs AI质检分工

| 检查类型 | 使用工具 | 原因 |
|---------|---------|------|
| 格式问题（比喻密度、禁词等） | 脚本 | 精确计数，不遗漏 |
| 内容质量（节奏、人物、氛围） | AI质检 | 需要语义理解 |
| 结构问题（衔接、钩子） | AI质检 | 需要上下文判断 |

---

## 二、环境要求

- Python 3.7+
- 无需额外依赖（仅使用标准库）

---

## 三、使用流程

### Step 1: 运行通用扫描器

```bash
python sop_scanner_generic.py [章节文件路径]
```

或扫描最近N章：
```bash
python sop_scanner_generic.py [正文目录] --recent 5
```

### Step 2: 查看报告

报告包含：
- 18维检查结果
- 违规项行号和内容
- 修改建议

### Step 3: 修复格式问题

根据报告逐项修复。

### Step 4: 运行增量检查器

```bash
python sop_scanner_v82_generic.py [章节文件路径]
```

### Step 5: AI质检

加载「审核技能」进行质量评估。

---

## 四、报告解读

### 关键检查项

| 检查项 | 含义 | 严重程度 |
|--------|------|----------|
| 不是...是... | 对比句式 | 🔴 零容忍 |
| 比喻密度 | 像/仿佛/犹如等 | 🟡 ≤5处 |
| 模糊修饰 | 某种/一种 | 🔴 零容忍 |
| AI收束结尾 | 他知道/从此刻起等 | 🔴 零容忍 |
| 冻结意象 | 陈词滥调 | 🟡 尽量避免 |
| 体感重复 | 同一感受多次 | 🟡 ≤3次 |

---

## 五、故障排除

### 脚本运行错误
- 确认Python版本：`python --version`
- 确认文件路径正确
- 确认文件编码为UTF-8

### 报告异常
- 确认章节文件格式正确
- 确认文件不为空

---

## 六、与技能文件的配合

| 阶段 | 加载技能 | 运行工具 |
|------|---------|---------|
| 创作后 | — | sop_scanner_generic.py |
| 格式修复后 | — | sop_scanner_v82_generic.py |
| 质检时 | 审核技能 | — |
| 修改后 | 修订技能 | sop_scanner_generic.py（重新扫描）|
