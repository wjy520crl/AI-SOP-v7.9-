# 常见错误速查 · 海报版

> 单页速查，可打印贴于工作台。红色=零容忍，黄色=注意，绿色=必须做到。

---

## 🔴 零容忍（必须 = 0）

### 1. 「不是...是...」句式
```
❌ 不是A，而是B
❌ 并非A，而是B
✅ 直接说B，或删除
```

### 2. 冻结意象（陈词滥调）
```
❌ 指节因用力而发白
❌ 嘴角勾起一抹弧度
❌ 眼神冷得像冰
❌ 倒吸一口凉气
❌ 空气仿佛凝固了
✅ 写具体动作/细节
```

### 3. AI收束式结尾
```
❌ 他知道...
❌ 他不知道的是...
❌ 从此刻起...
❌ 新的XX开始了
❌ 这一切才刚刚开始
✅ 用动作/物件/未完成收尾
```

### 4. 模糊修饰
```
❌ 某种感觉
❌ 一种情绪
❌ 似乎/好像（表不确定）
✅ 写具体，或删除
```

### 5. 章间断裂
```
❌ 本章前200字未回应前章钩子
✅ 必须：时间衔接 + 状态衔接
```

### 6. 解释性插入
```
❌ XX，不需要YY
❌ XX，意味着YY
✅ 删掉，用行动展示
```

## 🟡 密度控制（注意数量）

### 比喻密度
```
标准：≤5个/章（3000字）
检测：grep -E "像|仿佛|犹如|好似|如同|似的"
处理：删除冗余，保留最精准的1-2个
```

### 体感重复
```
标准：同一感受 ≤3次/章
常见：伤口疼、疲惫、寒冷、紧张
处理：换感官类型/换部位/用变体
```

### 形容词堆砌
```
标准：单个主体 ≤2个形容词
❌ 高大威猛、满脸胡须、眼神凶狠的男人
✅ 那个男人走了过来。很高，影子把路灯都遮住了。
```

### 逻辑连接词
```
避免：第一...第二...第三...
避免：首先...其次...最后...
避免：综上所述、总而言之
✅ 拆成动作段落
```

## 🟢 必须做到（底线要求）

### 开篇200字
```
必须有：动作 / 对话 / 冲突 / 关键事件
禁止：纯环境 / 纯内心独白
```

### 章末钩子
```
高潮/情感/对话章节 → A/B/C型强钩子
低潮章节 → D/E型弱钩子或无钩子
```

### 时间锚点
```
标准：≥3个明确时间点/章
形式：14:00 / 3小时后 / 灾变第X天
```

### 段落长度
```
标准：≤5行（手机屏）
处理：长段后接1-2行短段
```

### 句式波动
```
标准：禁止连续3句同长度
分布：短句40-50%，中句30-40%，长句10-20%
```

## 📊 评分标准

| 分数 | 等级 | 处理 |
|------|------|------|
| 9.5+ | 优秀 | ✅ 通过 |
| 9.0-9.4 | 良好 | ⚠️ 小修后通过 |
| 8.5-8.9 | 合格 | ❌ 修改后重检 |
| <8.5 | 不合格 | ❌ 建议重写 |

**正文及格线：9.0分**
**大纲及格线：9.5分**

## 🛠️ 快速检测命令

```bash
# 零容忍检查
grep -n "不是" [文件]              # R0.1
grep -nE "某种|一种" [文件]        # R0.5
grep -nE "他知道|他不知道|从此刻起" [文件]  # R0.3

# 密度检查
grep -nE "像|仿佛|犹如|好似|如同|似的" [文件]  # R1
grep -nE "感到|觉得|意识到" [文件]   # 情绪直通词
grep -nE "第一|首先|其次|综上所述" [文件]   # 逻辑词

# 一键全检
python quick_check.py [文件]
```

## 📝 替换表速查

### 情绪直通词 → 身体反应
```
感到紧张 → 手指在XX上收紧
感到害怕 → 后退一步，后背抵着墙
感到疼痛 → 闷哼一声，咬住牙
意识到XX → （删掉）
```

### 沉默填充 → 动作
```
安静了几秒 → [角色]把XX叠成方块，又展开
沉默在空气中蔓延 → 风从破洞灌进来
```

### 体感变体
```
伤口疼 → 传来撕裂感 / 在发烫 / 一跳一跳地疼
疲惫 → 手按住膝盖才站起来 / 眼皮往下沉
寒冷 → 寒意从骨头缝里渗出来 / 手指冻得发僵
```

## 🎯 章节类型标记

| 类型 | 标记 | 钩子要求 |
|------|------|----------|
| 高潮 | 📍 | A/B/C型强钩子 |
| 低潮 | 🌙 | D/E型弱钩子或无 |
| 情感 | 💔 | C型情感钩子 |
| 对话 | 💬 | B/C型钩子 |

**A. 动作悬念** = 未完成动作
**B. 信息悬念** = 新发现/线索
**C. 情感悬念** = 内心波动
**D. 弱钩子** = 状态定格
**E. 无钩子** = 开放式结尾

---

## 🔗 章节节奏分布（40章/卷）

```
高潮章节（📍）：12-15章，每2-3章一次
低潮章节（🌙）：10-12章，每2-3章一次
情感章节（💔）：6-8章，每5-6章一次
对话章节（💬）：8-10章，每4-5章一次

禁止：连续3章同类型
```

## 💡 一句话原则

> **写你看见的，不是你想的。**
> 
> **用身体反应代替情绪描述。**
> 
> **用动作收尾代替总结句。**
