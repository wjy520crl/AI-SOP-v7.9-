# 每章创作prompt模板（通用版·精简版）

> 创作专用精简模板。不含质检内容，质检请使用「审核技能」。
> 使用方式：将`[变量]`替换为实际内容，作为创作任务的完整prompt。

---

## 模板：主笔创作+浓缩包报告

```

2. 读取前章（第[X-1]章）的浓缩包状态

## 绝对禁止（零容忍）

详见《核心规则库》第一章绝对禁止列表（R0）。

核心要点：
1. 「不是...是...」句式：全文0处
2. 冻结意象：嘴唇干裂、指节发白、嘴角勾起、倒吸一口凉气、空气凝固
3. AI收束式结尾：禁止
4. 解释性插入：禁止
5. "某种/一种"模糊修饰：禁止
6. 章间断裂：禁止

## 写作约束

详见《核心规则库》第二章写作规则（R1-R9）。

核心要点：
- R1 比喻密度：全章≤5个
- R3 开篇200字：必须有抓手
- R7 章间衔接：必须回应前章钩子
- R8 章末钩子：根据章节类型选择
- R9 时间锚点：至少3个
```
