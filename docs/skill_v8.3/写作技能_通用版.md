## 一、文笔五律（核心）

### 节奏（Burstiness）
- 短句为主，长短穿插。一句话只讲一件事。
- **句式必须波动。** 禁止连续 3 句同长度（全是短句→像剁肉；全是长句→像念经）。刻意制造突变：一段平滑叙述后突然砸一个 3 字短句。
- 段落 ≤5 行（手机屏）。拒绝大段密排。
- 动作用短句推进，心理穿插在行动中。
- **句子长度分布参考**：短句（≤15字）占 40-50%，中句（15-30字）占 30-40%，长句（>30字）占 10-20%。拒绝全篇均匀分布。

### 逻辑
- 观点前置。先出结论再展开。不跳步不绕弯。
- 人物做一件事的原因，在行动前或行动中自然交代——不事后解释。
- 因果链清晰，读者不需要回头再读。

### 语言
- 用词干净。不浮夸形容词、不强行煽情、不网络烂梗。
- 语感温和平等，不居高临下说教。
- **"不是...是..."硬约束：全章 0 处。零容忍。** 禁止任何形式的"不是...而是...""并非...而是..."对比句式。

### 多样性（Perplexity）
- **词汇不可预测。** 避免同一段内重复同一个关键词/动词（如连续三句用"看"→换"扫/瞥/盯/打量"）。
- **拒绝平滑感。** 好的写作要偶尔让读者磕一下——一个不常见的比喻、一个突然的短句截断、一个出人意料但准确的动词。
- **信息密度波动。** 松→紧→松→紧，制造阅读节奏。

### 情绪
- 共情 > 批判。先理解角色再写反应。
- 留白——不把感受说死，留一点让读者自己品。
- 情绪曲线：铺垫→蓄力→爆发→余韵。

## 二、番茄铁律

| # | 铁律 |
|---|------|
| 1 | 每 ~300 字必须有信息增量/冲突/反转 |
| 2 | 章末必须留钩子（悬念/反转/情绪，至少占一个） |
| 3 | 情绪曲线完整：铺垫→蓄力→爆发→余韵 |
| 4 | 利用信息差：读者知道 ≠ 角色知道 |
| 5 | 角色说话语气差异：每个角色应有独特的说话方式 |
| 6 | **角色台词职业底色**：每个角色的对话必须反映其背景训练 |

## 四、写作手法

- 多写身体感受——渴、累、手磨破、泥土腥味、木板扎手、后背贴墙的凉意
- 主角可以有"无效时刻"——走神、发呆、注意到没意义的东西
- 人物可以说废话、话说一半被打断
- 加一两个"没用但鲜活"的细节
- 内心独白不要写成分析报告
- 对话：打断、欲言又止；潜台词 > 台词
- **体感优先**：写动作时写重量感、写环境时写气味质感

## 五、禁止事项

| ❌ | ✅ |
|----|----|
| AI 收束式结尾 | 用具体动作或物件收尾 |
| 排比句收束段落 | 用单一细节锚定 |
| 过度解码人物心理 | 行动和对话传递心理 |
| 金句化说教 | 角色用自己的话表达 |
| "不是...是..." | **零容忍，0 处** |
| meta梗/打破第四面墙 | 用剧情内单位替代 |
| 角色拥有超出设定的知识 | 角色只能知道设定范围内的知识 |

## 七、硬核六条

### 1. 细节必须有用
- 所有描写必须对剧情/人设/伏笔有作用

### 2. 角色锁定
- 固定角色不许增减，每人台词有专属语感

### 3. 杜绝空降结论
- 所有猜测、判定都要有可见细节做依据

### 4. 杜绝体感重复
- 同一体感每章最多3次，换部位或换感官类型

### 5. 拒绝模板化结构
- 剧情推进自然，不按模板流水线走流程

### 6. 克制白描
- 不刻意堆文艺辞藻，不刻意渲染空洞氛围

## 九、展开策略（写够3000-3500字）

### 每个核心节拍至少 400-500 字

### 战斗场景展开公式
至少 3 轮攻防交替：
```
① 发现/锁定（50字）→ ② 攻击/规避（100字）→ ③ 身体感受/环境变化（100字）
```
重复 3 轮 = 750 字

### 群像场景展开公式
≥3 人同时出场时，每人至少 1 句台词 + 1 个动作

### 环境描写展开公式
每进入一个空间，写 2 个感官细节（触觉/嗅觉/听觉）

### 对话展开公式
禁止连续 3 句纯对话，每段对话间插入动作或身体感受

### 心理描写展开公式
禁止"他知道/她意识到/他明白"，改为动作碎片
