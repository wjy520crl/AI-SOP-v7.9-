# 快速开始指南（通用版）v1.0

> 5分钟上手小说创作流水线。本文档是整个技能体系的入口。

---

## 一、5分钟了解体系

本体系由8个技能文件组成，覆盖从项目初始化到成稿质检的完整流程：

| 技能 | 一句话介绍 |
|------|-----------|
| **初始化技能** | 填写项目设定（世界观、角色、风格），是所有后续工作的基础 |
| **大纲生成技能** | 生成四级大纲（卷→章→场景→节拍），设计张力曲线和伏笔体系 |
| **大纲审核技能** | 对大纲进行结构、节奏、伏笔、衔接四维审核 |
| **写作技能** | 核心写作规范，包含感官密度、句式节奏、对话潜台词等具体规则 |
| **每章创作prompt模板** | 单章创作的标准化prompt，填入参数即可生成正文 |
| **审核技能** | 对已完成章节进行28维质量审核，输出审核报告 |
| **修订技能** | 根据审核报告定位问题并逐项修复 |
| **核心规则库** | 所有技能共享的底层规则，包含禁用词表、检查项、示例库索引 |

---

## 二、第一步：完成初始化

**加载技能**：初始化技能_通用版.md

**操作**：
1. 打开初始化技能文件
2. 按模板填写项目设定表
   - 书名、类型标签、目标字数
   - 世界观核心规则（3-5条）
   - 主角设定（性格、动机、弧光阶段）
   - 关键配角设定（3-5人）
   - 风格定位（参考作品、意象域选择）
3. 保存为 `[书名]_项目设定.md`

**产出物**：一份完整的项目设定文档

---

## 三、第二步：生成第一章大纲

**加载技能**：大纲生成技能_通用版.md

**操作**：
1. 先生成全书卷级大纲（Step 1）
2. 再生成第一卷的章级大纲（Step 2）
3. 对前3-5章生成场景级大纲（Step 3）
4. 使用大纲审核技能检查大纲质量

**产出物**：`[书名]_全书大纲.md` + `[卷名]_章级大纲_第X-X章.md`

---

## 四、第三步：创作第一章

**加载技能**：写作技能_通用版.md + 每章创作prompt模板_通用版.md

**操作**：
1. 打开每章创作prompt模板
2. 填入本章参数（章节号、场景、节拍、伏笔等）
3. 将写作技能中的核心规则作为约束条件附加到prompt中
4. 发送给AI生成正文
5. 检查生成结果是否符合大纲节拍

**注意事项**：
- 每章生成后立即与大纲核对，偏差及时修正
- 注意章末钩子类型（A/B/C/D/E）是否与大纲一致
- 保留每章的章末状态记录（人物位置、时间、关键物品）

**产出物**：`第X章_[章名].txt`

---

## 五、第四步：质检与修改

### 5.1 运行自检脚本

```bash
python quick_check.py 第X章_[章名].txt
python quick_check.py 第X章_[章名].txt -o report.txt
```

脚本会自动检查8项指标，零容忍项不通过则必须修改。

### 5.2 加载审核技能

**加载技能**：审核技能_通用版.md

对章节进行28维全面审核，生成审核报告。

### 5.3 如不通过，加载修订技能

**加载技能**：修订技能_通用版.md

根据审核报告中的问题清单逐项修复。

**修订流程**：
1. 读取审核报告，按严重程度排序
2. 零容忍问题优先修复
3. 密度问题批量修复
4. 修复后重新运行自检脚本验证
5. 全部通过后进入下一章

## 六、常见问题FAQ

**Q1：必须按顺序使用所有技能吗？**
A：核心流程是 初始化→大纲→写作→审核→修订，这个顺序建议遵守。但大纲审核技能是可选的，如果你对大纲质量有信心可以跳过。

**Q2：每章生成多少字合适？**
A：建议每章2000-4000字。太短无法完成场景节拍，太长容易失控。具体根据大纲中的场景数量调整。

**Q3：AI生成的正文质量不稳定怎么办？**
A：这是正常现象。关键是质检环节要严格——用自检脚本过滤硬伤，用审核技能过滤软伤，用修订技能定向修复。流水线的价值在于标准化，不在于一次成功。

**Q4：大纲写到一半发现需要修改怎么办？**
A：直接修改大纲，但要在变更记录中注明。跨卷修改时注意检查伏笔一致性和人物弧光连续性。参考大纲生成技能中的"跨卷管理"章节。

**Q5：自检脚本的检查项可以自定义吗？**
A：可以。打开 quick_check.py，修改 CHECKS 列表中的正则表达式和阈值即可。建议保留8个基础检查项，根据个人需求增减。

**Q6：核心规则库和其他技能是什么关系？**
A：核心规则库是底层规则集，其他技能引用其中的规则。如果修改了核心规则库中的某条规则，所有引用该规则的技能都会受影响。建议先熟悉核心规则库，再使用其他技能。

**Q7：写作过程中发现大纲不合理怎么办？**
A：记录问题，在当前章节完成后统一调整大纲。不要边写边改大纲，容易导致前后矛盾。调整后记得更新前情提要和伏笔总表。

**Q8：如何保证多卷之间的一致性？**
A：使用大纲生成技能中的"跨卷管理"模块，维护全书伏笔总表、设定变更记录和人物弧光追踪表。每卷开头生成前情提要。
