# 大模型质检模板 v1.0（通用版·文学质量评估）

## 用途
在正则扫描器（格式检查）通过后，使用大模型进行第二道质量关卡。

## 使用方式
将本章正文（Part 1）+ 大纲节拍 + 前章浓缩包发送给大模型，按以下模板评估。

---

## 质检Prompt模板

```
你是一位资深网文编辑，请对以下章节进行文学质量评估。

## 章节信息
- 书名：《[书名]》
- 第[X]章：[标题]
- 类型：[高潮/低潮/情感/对话]
- 字数：[实际字数]

## 大纲节拍（必须全部完成）
1. [节拍1]
2. [节拍2]
...

## 前章结尾状态
[浓缩包chapter_end_state]

## 待评估正文
[粘贴Part 1正文]

---

## 评分维度（每项1-10分，保留一位小数）

### 1. 大纲对应度（权重20%）
- 所有节拍是否完成？
- 时间线是否与大纲一致？
- 钩子类型是否正确？

### 2. 节奏与张力（权重25%）
- 高潮章节：战斗/发现是否有紧迫感？是否有"差点失败"的瞬间？
- 低潮章节：是否有微小变化打破平淡？还是纯粹无聊？
- 情感章节：情绪是否有递进？是否有"崩溃边缘"的描写？
- 对话章节：对话是否有信息差？是否有试探/博弈？

### 3. 感官细节（权重20%）
- 是否调动了多种感官（视觉、听觉、嗅觉、触觉、温度）？
- 环境描写是否具体（而非笼统的"灰雾弥漫"）？
- 战斗场景是否有身体感受（疼痛、疲惫、耳鸣）？

### 4. 情绪深度（权重20%）
- 主角内心活动是否具体（而非笼统的"他很害怕"）？
- 是否有矛盾心理（想做但不敢做）？
- 情感锚点是否有冲击力？

### 5. 冗余检测（权重15%）
- 是否有重复描写（同一意象出现3次以上）？
- 系统操作/数值计算是否过于冗长？
- 日常描写是否过于流水账？
```

## 质检流程（迭代循环）

```
Step 1: 正则扫描器（格式检查）
  - 禁止句式、关键词频率、时间衔接、字数、英文混入
  → 不通过：直接打回修改
  → 通过：进入Step 2

Step 2: 大模型质检（质量评估）
  - 大纲对应度、节奏张力、感官细节、情绪深度、冗余检测
  → 输出评分 + 具体优化建议

Step 3: 评分判定
  → ≥9.5：通过，写入评分，进入下一章
  → <9.5：进入Step 4

Step 4: 根据质检建议修改
  - 读取质检报告中的优化建议
  - 逐条修改正文
  - 修改后回到Step 1重新扫描

循环上限：5轮。5轮后仍未达9.5，记录最终评分并标注"需人工复审"。
```

## 评分标准参考

| 综合评分 | 等级 | 说明 |
|---------|------|------|
| 9.5+ | 优秀 ✅ | 通过，进入下一章 |
| 9.0-9.4 | 良好 | 修改后重检 |
| 8.5-8.9 | 合格 | 修改后重检 |
| 8.0-8.4 | 待改进 | 修改后重检 |
| <8.0 | 不合格 | 建议重写 |
