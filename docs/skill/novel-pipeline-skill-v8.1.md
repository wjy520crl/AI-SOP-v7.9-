# novel-pipeline v8.1 · 每章子任务标准prompt模板

> 使用方式：每章创作时，将此模板中的`[变量]`替换为实际内容，作为子任务的完整prompt。

---

## v8.1 更新说明（2026-05-13）

基于第1-3章AI味审计的实战反馈，新增以下强化规则：

### 新增规则
- **R1 比喻密度硬约束**：从"≤2处/千字"收紧为"≤1.5处/千字"，且每页（约500字）最多2个比喻
- **R2 解释性插入零容忍**：禁止"XX，不需要YY""XX，意味着YY"等解释性插入，信任读者
- **R3 开篇200字规则强化**：前200字必须包含动作/对话/冲突/系统事件之一，禁止纯环境描写开篇
- **R4 "某种/一种"禁用**：禁止"某种XX""一种XX"模糊修饰，必须具体化或删除
- **R5 体感重复上限**：同一身体感受（伤口痛、疲惫、寒冷等）每章最多出现3次，超限必须换表达方式
- **R6 grep自检流程**：初稿完成后必须运行6项grep检查，全部通过方可提交

### 修改规则
- **D24感官替代**：新增替换表（见附录A）
- **D28沉默填充**：新增替换表（见附录A）
- **PZ-3形容词堆砌**：从"≤3个"收紧为"≤2个"

```
- 类型：末世+系统+基地守塔

- 视角：第三人称有限视角（陈默）

## 前章回顾（需呼应）
[前一章最后3段内容]

## 第[X]章任务
[本章剧情要点，3-5个]

## 当前浓缩包状态
### chapter_end_state（前章末）
[前章的chapter_end_state完整内容]

### character_registry（已有角色）
[已有角色列表及关键设定]

### location_registry（已有地点）
[已有地点列表]

### active_subplots（活跃支线）
[活跃支线列表及状态]

### physical_anchor_items（物象载体）
[已有物象载体列表及状态]

### hook_history（最近5章钩子）
[最近5章钩子记录]

### emotional_pressure_map（情感压强）
[最近5章情感压强序列]

## 绝对禁止（零容忍——违反即退回）
1. 「不是...是...」句式：全文0处（含变体"不是X。他只是Y。""不是X——是Y"）
2. 冻结意象：嘴唇干裂、指节发白、嘴角勾起、倒吸一口凉气、眼窝深陷、空气凝固、时间仿佛静止
3. AI收束式结尾："他知道...""从此刻起...""新的XX开始了""这是XX的开始""一切都变了"
4. 解释性插入："XX，不需要YY""XX，意味着YY"——如果删掉它意思不变，就删掉
5. "某种/一种"模糊修饰：必须具体化或删除

## 写作约束（D24-D28 + R1-R6）

### D24 感官替代（用动作/环境传递情绪）
- 禁止："他很紧张""她感到害怕""陈默意识到""他觉得"
- 替换表见附录A

### D25 句式节奏
- 战斗场景：短句推进（单句≤15字），段落≤3句
- 过渡场景：中等信息密度，禁止连续3句以上纯描写
- 对话场景：节奏跟随说话者，允许碎片化

### D26 角色语言破壁
- 压力升高时：句子变短，修饰词减少，专业角色用术语

### D27 意象域统一
- 本场景主导意象域：[根据场景选择：金属/机械 | 冷/热 | 光/暗 | 压力/重量]
- 禁止跨域比喻

### D28 沉默填充（用动作替代时间填充）
- 禁止："安静了几秒""沉默在空气中蔓延""没有人说话"
- 替换表见附录A

### R1 比喻密度
- 全章比喻≤1.5处/千字（约3000字章节最多4-5个比喻）
- 每页（500字）最多2个比喻
- 比喻必须服务于信息传递，禁止装饰性比喻

### R2 解释性插入
- 写完每句话后问自己：删掉它意思会变吗？不会就删

### R3 开篇200字
- 前200字必须包含：动作/对话/冲突/系统事件 之一
- 禁止纯环境描写开篇

### R4 "某种/一种"禁用
- "某种声音"→具体描述声音特征
- "一种XX的感觉"→直接描写感受
- "某种不详的预兆"→删除或改为具体细节

### R5 体感重复上限
- 同一身体感受每章最多3次
- 超限必须换表达方式（见附录A替换表）

### R6 主语省略规则
- 连续3个"陈默+动词"后，必须省略主语或换"他"/环境作主语

## AI味七禁区
1. 禁止陈词滥调（嘴角勾起一抹弧度、指节因用力而发白等）
2. 禁止逻辑连接词（首先/其次/综上所述/总而言之）
3. 禁止形容词堆砌（单个主体≤2个形容词）
4. 禁止刻板化描写（写你"看见"的具体细节）
5. 禁止细节过度（2-3个有叙事功能的东西即可）
6. 禁止清单式描摹（必须有叙事焦点）
7. 禁止情绪直白+空洞结尾

## 输出要求

### Part 1：正文
- 字数：3000-3500字
- 视角：第三人称有限视角（陈默）
- 章末钩子：[本章钩子类型和要求]
- 用中文输出，直接输出正文

### Part 2：浓缩包更新报告（必须输出）
[与v8.0相同，10个模块]

### Part 3：自检报告（v8.1新增——必须输出）
完成正文后，必须逐项自检并输出：

| 沉默填充 | grep -c "沉默\|安静了\|空气凝固" | [X]处（必须=0） |
| 比喻密度 | grep -c "像\|仿佛\|好似" | [X]处（≤5） |
| 模糊修饰 | grep -c "某种\|一种" | [X]处（必须=0） |
| 形容词堆砌 | grep -c "的.*的.*的" | [X]处（建议≤2） |

#### 3.2 体感重复检查
| 体感 | 出现次数 | 位置 |
|------|---------|------|
| [体感1] | [X]次 | [行号] |
| [体感2] | [X]次 | [行号] |

#### 3.3 主语重复检查
- 最长连续"陈默+动词"次数：[X]次（建议≤3）
- 位置：[行号范围]
```

## 附录A：替换表

### A1 情绪直通词替换表
| 禁止 | 替换为 |
|-----|-------|
| 感到紧张 | 手指在XX上收紧 / 呼吸变浅 |
| 感到害怕 | 后退一步，后背抵着墙 / 手握紧XX |
| 感到疼痛 | 闷哼一声，咬住牙 / 动作顿了一下 |
| 感到疲惫 | 手按住膝盖，慢慢站起来 / 眼皮往下沉 |
| 意识到XX | （删掉，让读者自己意识到） |
| 觉得XX | （删掉，或改为具体动作） |
| 发现XX | 视线落在XX上 / XX映入眼帘 |

### A2 沉默填充替换表
| 禁止 | 替换为（选一个符合角色特征的） |
|-----|-------|
| 安静了几秒 | [角色]把XX叠成方块，又展开 / [角色]的拇指在XX上划了一下 |
| 沉默在空气中蔓延 | [角色]把XX轻轻放在XX上，金属碰撞声很轻 / 风从破洞灌进来 |
| 没有人说话 | [角色]低头看着自己的手 / [角色]的视线移向窗外 |

### A3 体感重复替换表
| 原始表达 | 变体1 | 变体2 | 变体3 |
|---------|-------|-------|-------|
| 伤口疼 | 伤腿传来撕裂感 | 裂开的伤口在发烫 | 裤脚上的血迹又扩大了一圈 |
| 疲惫 | 手按住膝盖才站起来 | 眼皮往下沉，晃了一下头 | 靠在墙上，闭上眼，三秒后睁开 |
| 寒冷 | 寒意从骨头缝里渗出来 | 手指冻得发僵 | 呼出的气在空气中凝成白雾 |
| 心跳加速 | 心跳撞击肋骨 | 脉搏在耳膜上跳动 | 血液涌向太阳穴 |

### A4 "某种/一种"替换表
| 禁止 | 替换为 |
|-----|-------|
| 某种声音 | 具体描述：嘶嘶声/金属刮擦声/低频震动 |
| 某种感觉 | 直接描写感受：胃里翻搅/后颈发凉 |
| 某种不详的预兆 | 删除，用具体细节替代 |
| 一种低沉的呜咽 | 低沉的呜咽 |
| 一种XX的感觉 | 直接写感受，不加"一种" |
