# AI辅助小说创作流水线（SOP v7.1）

## Overview

基于多Agent协作的网文长篇连载工业化创作流水线。架构分为三层：

- **安全网**（硬约束）：文笔五律、AI味七禁区、硬核六条、质检硬约束
- **偏差层**（可控破坏）：6组21模块偏差指令，打破AI写作模式化惯性
- **柔性层**（自适应）：人物弧光、叙事直觉、道德基线动态漂移

流水线步骤：步骤0（浓缩包）→ 步骤1（主笔）→ 步骤2（台词优化）→ 步骤2.5（AI味审计）→ 步骤3（质检）→ 步骤4（存盘）→ 步骤5（更新浓缩包）→ 步骤6（发用户）→ 步骤7（自进化）→ 步骤8（章回顾，每10章）

## 关键规则速查

### 硬约束（质检一票否决）

1. 「不是...是...」全章 ≤1 处（必须grep+人工复核）
2. 章末必须有钩子（悬念/反转/情绪至少一个）
3. 禁止AI收束式结尾（「他知道...」「从此刻起...」「新的XX开始了」等）
4. EVE Lore零违规
5. 大纲无重大偏离

### AI味七禁区

1. **陈词滥调**——禁止高频模板化表达（「嘴角勾起一抹弧度」「指节因用力而发白」等）
2. **逻辑连接词**——禁止「首先/其次/综上所述/总而言之」等议论文过渡词
3. **形容词堆砌**——单个主体 ≤3 个形容词，比喻 ≤2处/千字
4. **刻板化描写**——拒绝固定印象模板，写你"看见"的具体细节
5. **细节过度**——不写满，留缝隙，2-3个有叙事功能的东西即可
6. **清单式描摹**——禁止扫描式并列描摹，必须有叙事焦点
7. **情绪直白+空洞结尾**——用动作/环境间接传递，禁止「或许...也或许...」

### 硬核六条（一票否决）

1. **细节必须有用**——删掉会丢信息才留
2. **角色锁定**——不凭空客串，台词有专属语感
3. **杜绝空降结论**——判定必须有可见细节做依据
4. **杜绝体感重复**——同一体感不连续出现
5. **拒绝模板化结构**——不按固定流水线推进
6. **克制白描**——不堆文艺辞藻，不渲染空洞氛围
