# AI辅助小说创作流水线 SOP v7.9

基于多Agent协作的网文长篇连载工业化创作流水线，适用于EVE Online等科幻世界观的长篇小说创作。

## 架构概览

```
安全网（硬约束）→ 偏差层（可控破坏）→ 柔性层（自适应）→ 工具拦截层（自动化扫描）
```

## 核心文件

| 文件 | 说明 |
|------|------|
| `流水线SOP.md` | v7.9完整标准文档（28维度审阅 + D24-D28文学质感规则） |
| `tools/sop_scanner.py` | 自动化质量扫描器（13维检测，零容忍硬约束拦截） |
| `novel-pipeline-skill-v7.9.md` | SOLO技能包（可直接上传为自定义技能） |
| `浓缩包模板_v7.7.yaml` | 章节浓缩包YAML模板 |

## 流水线步骤

```
步骤0 浓缩包 → 步骤1 主笔 → 步骤2 台词优化 → 步骤2.4 强制扫描
→ 步骤2.5 AI味审计 → 步骤3 质检 → 步骤4 存盘 → 步骤5 更新浓缩包
→ 步骤6 发用户 → 步骤7 自进化 → 步骤8 章回顾(每10章) → 步骤9 作家在环(每10-15章)
```

## 28维度审阅体系

- **D1-D12**：基础文笔、感官分配、对话平衡、节奏控制、结构/伏笔/EVE/视角
- **D13-D19**：支线缠绕度、主角道德灰度、对手智能、物象载体、设定交代、思想锚点、开篇方式
- **D20-D23**：情感压强、配角辨识度、信息包装度、跨章重复检测
- **D24-D28**（v7.9新增）：感官替代、句式节奏、角色语言破壁、意象域统一、沉默填充

## 硬约束（零容忍）

1. `不是...是...` 句式：全章0处
2. 冻结意象：嘴唇干裂、指节发白、嘴角勾起、倒吸一口凉气等
3. 章末必须有钩子
4. 禁止AI收束式结尾

## 扫描器使用

```bash
# 扫描单章
python tools/sop_scanner.py --chapter "chapters/第一卷/第X章.md" --window 6

# 返回码：0=PASS, 1=WARN, 2=FAIL
```
